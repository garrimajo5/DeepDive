# MOD-019 — атлас табло тревог

Issue: #198. База origin/main: `5ccbbbeb0073e4ddb3ad95942766a174e9769e20`. Ветка `art/MOD-019-tablo-atlas`.

Исходники: принятый ART-025 — `docs/concept-art/tablo-trevog-list.png`, `tablo-trevog-mostik.jpg`, решения в `tablo-trevog.md`. Геометрию собирает игровой код; этот заказ содержит текстуры, GLB и Meshy не нужны. Расход кредитов — 0.

## Файлы

- `tablo-color.png`: 2048×256 RGB, погашенное табло; #0B1C24 подложка, #66747A буквы, #514D43 неактивные углы и разделители, #8C806B заклёпки.
- `tablo-color-on.png`: 2048×256 RGB; те же пиксели букв и углов становятся #FFB259, остальная поверхность идентична.
- `tablo-mask.png`: 2048×256 L (8 бит, один канал), ровно три значения: 0 — без свечения, 128 — углы, 255 — буквы. Не содержит альфы или палитровой индексации.
- `preview.png`: 1600×720. Сверху оба UV-атласа, ниже физические пропорции поверхности 7,2×0,25 м, внизу табло 490×17 px без bloom — ориентир масштаба с телефона, не скриншот Godot.
- `fields.json`: точные границы, UV, ширины, прямоугольники надписей и параметры шрифта.
- `src/build_atlas.py`: воспроизводимая сборка из шрифта и проверки. Требует Pillow, numpy и установленный DejaVu Sans Condensed Bold; путь к шрифту указан в начале файла. Сам файл шрифта не включён.

## Шрифт и пропорции

DejaVu Sans Condensed Bold (`DejaVuSansCondensed-Bold.ttf`), исходный кегль 35 px, общий для всех пяти надписей. Надписи строго из issue, включая длинное тире U+2014 в «ИЛ — СОНАР СЛЕП». Без текста вне полей.

Важно: отношение сторон PNG — 8:1, а физической поверхности — 28,8:1. Поэтому вертикальная растяжка рисунка в UV-атласе намеренная. По X 1 px = 3,515625 мм, по Y 1 px = 0,9765625 мм. Прямоугольник чернил каждой надписи высотой 143 px соответствует 0,13965 м. Не размещать PNG на плоскости с пропорциями 8:1: буквы останутся вытянутыми. Физически правильный вид показан третьей полосой превью.

Углы: горизонтальное плечо около 6,3 см, вертикальное около 6,25 см; толщина около 1,4 см. В UV это разные количества пикселей по осям. Неактивные углы тёмные, активные яркие — состояние отличается также яркостью и появлением заметных углов, а не только оттенком.

## Маска и материал

Контуры букв и углов заданы единой маской. В исходных текстурах нет промежуточных значений маски и нет градиентных ореолов. Растеризация букв бинарная; сглаживание при уменьшении даёт фильтрация цветовой текстуры. Pixel diff между цветными файлами **в точности** равен mask > 0. Вне маски атласы совпадают полностью. Заклёпки и разделители никогда не светятся.

Маску импортировать как линейные данные без sRGB, без потерь и без mipmaps; для распознавания классов использовать nearest. При нормализованном чтении угол = 128/255, буква = 1. Нельзя считать промежуточное значение, полученное линейной фильтрацией границы буквы, новым углом. Цветные атласы можно фильтровать линейно и использовать анизотропную фильтрацию для вытянутой поверхности.

На активном поле буквы светятся постоянно. При мигании главной тревоги переключаются только пиксели класса 128 между on/off (1 Гц по принятому ART-025); класс 255 не гаснет. Неактивное поле берёт off, эмиссия 0. Мощность эмиссии настраивается в материале игры; художественный цвет — #FFB259. Новых условий тревог или анимаций не добавлено.

## Проверки и ограничения

Скрипт проверяет разрешения и бюджет, значения маски {0,128,255}, отсутствие перекрытия букв и углов, точное совпадение изменённых пикселей с маской и неизменность фона. Три рабочих PNG занимают около 4–6 КБ каждый при лимите 1 МБ. Превью просмотрено: все пять надписей читаются на полосе шириной 1536 px, то есть уже при размере меньше контрольных 1600 px.

При высоте всего табло 17 px буквы имеют высоту около 9,5 px; нижняя полоса показывает этот ограниченный запас читаемости честно, без искусственного увеличения. Реальная читаемость в перспективе, при движении камеры и на физическом телефоне требует проверки после интеграции. Табло из кресла пилота по-прежнему видно при взгляде вверх, его расположение этим заказом не меняется.

Код игры, docs/, models/ и тесты не изменены. Палитра: #0B1C24, #66747A, #514D43, #8C806B, #FFB259; красного нет.
