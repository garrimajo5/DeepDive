## Файлы и размеры

Все три GLB совмещать в (0,0,0), без автоматического центрирования. Общий pivot — центр основания реактора на полу, Y=0. Метры, Y вверх, условный перед −Z; конструкция почти симметрична. Мировую позицию (0;0;17,2) задаёт игра. Узлы без трансформов, масштаб1; анимации и скелета нет.

|---|---|---|---|
| reaktor-osnova.glb | 1,90 / 3,15 / 1,90 | основание Y0…0,35; крышка Y2,85…3,15 | 1524 / 2000 |
| reaktor-kozhuh.glb | 1,76 / 2,50 / 1,44 | стекло Y0,35…2,85, кольца Y0,55/1,55/2,55 | 2115 / 2500 |
| reaktor-sterzhen.glb | 0,64 / 2,50 / 0,64 | Y0,35…2,85 | 222 / 500 |

Основание имеет план1,9×1,9 и высоту0,35; крышка — план1,3×1,3 и высоту0,30. Большая общая высота файла основы включает пустое пространство между основанием и крышкой, это одна сетка с двумя несвязанными компонентами.
Диаметр именно стекла1,24м. Наружный диаметр кольца около1,44м, вместе с противоположными соплами ширина1,76м. Толщина каждого кольца0,18м; диапазоны Y0,46…0,64 /1,46…1,64 /2,46…2,64. Отклонение центров от заданных высот меньше1мм. Шесть сопел — по два на кольцо; пар не моделировался.

`preview.png` — 1024×1024, реальные рендеры финальных сеток с трёх сторон, линейка в метрах и разнесённая схема деталей. Разнесение в нижней схеме только для объяснения: в GLB все pivot остаются общими.
`*-color.png` — внешние копии встроенных текстур цвета1024×1024; `*-emission.png` — внешние копии разрешённых масок свечения. Для импорта нужны только GLB: все текстуры внутри. `base-reference.jpg`, `ring-reference.jpg`, `rod-reference.jpg` — входные референсы Meshy, выделенные из принятого концепта встроенным ImageGen.

## Материалы Godot

- Основа/крышка: один PBR metallic-roughness материал, metallic0,55, roughness0,60; одна текстура цвета и маска emissiveTexture только на голубых индикаторах. emissiveFactor=(1,1,1), интенсивность умеренная.
- Кожух: **одна сетка, два surface/material**. Металлические кольца непрозрачные, с аналогичным PBR и emissiveTexture голубых вставок. Стекло — отдельный материал внутри той же сетки: alphaMode=BLEND, alpha0,14, roughness0,22, металлическость0, двустороннее. Стекло не светится; отдельная карта рефракции не нужна. Простая прозрачность выбрана для совместимости с GL Compatibility.
- Стержень: светлая ровная текстура без узоров/красного, metallic0, roughness0,45, emissiveFactor=(1,1,1). Нейтрально-белое свечение в файле намеренно: игра меняет цвет состояния. Для нормы задать albedo/emission #6FE3FF, для перегрева — цвета принятого концепта; для сброса выключить emission и затемнить материал. Не тонировать весь кожух вместе со стержнем. При нескольких реакторах дублировать материал перед изменением состояния.

Палитра: #8C806B металл, #514D43 швы, #0B1C24 тёмные панели, #67DDEB индикаторы, #9AD9E8 стекло, #EBEBEB нейтральный стержень, #6FE3FF состояние нормы. Текстура металла содержит вариации света генерации; чистого красного и нарисованного перегрева нет. Статические части неподвижны; анимация цвета/яркости и пар остаются за игрой.

## Генерация, происхождение и доработка

Meshy CLI0.4.0, image-to-3d standard, should-texture=true, enable-pbr=false, texture-resolution=2k; затем remesh topology=triangle, целевые бюджеты: base850, ring650, rod350. После ремеша: base762, ring673, rod222 треугольника. Кольцо повторено3раза; основание повторено для крышки с переворотом и размерами крышки. Стеклянная цилиндрическая поверхность48сегментов/96треугольников добавлена локально для точного диаметра и надёжной прозрачности, вместо попытки запечь стекло и стержень в один непрозрачный меш Meshy. Сумма кожуха673×3+96=2115. Это сборка из семи простых частей: основание, крышка, три кольца, стекло, стержень.

Локальные проекты Meshy лежат в `work/reactor-work/20261019_230719_base_01a155c6`, `20261019_230723_ring_01a155c6`, `20261019_230728_rod_01a155c6`. ID достаточны для повторного скачивания и новых вариантов без новой генерации.

Промпты ImageGen:
- Base: из принятого реактора выделить только низкое квадратное основание1,9×1,9×0,35м, скошенные углы, центральное круглое гнездо, охристый периметр и тёмные панели, маленькие голубые индикаторы, белый фон; без стержня/кожуха/колец/крышки.
- Ring: одно полое охлаждающее кольцо с видимым фоном через центр, охристый металл, два противоположных сопла, голубые вставки; без пара, стекла, стержня и остальных деталей.
- Rod: один прямой цилиндрØ0,64×2,5м по стержню концепта, ровный светлый нейтральный цвет, без колец, пятен, красного и металлических крышек.

Свечение и прозрачность настроены локально в Blender4.5.9 и сохранены в GLB. Мелкие болты/швы в основном текстурой. Крышка повторяет мотив основания, а не копирует все детали перспективы; кольца немного гранёные после ремеша. Это упрощения под бюджет, не новые сюжетные решения. Вопросов к владельцу нет.

## Проверка

Проверены бинарные GLB: glTF2.0, одна сетка на файл, без трансформов узлов/анимаций/скелета; размеры, бюджеты и PNG1024² внутри; каждый GLB меньше1,8МБ. Кожух имеет два материала для независимой прозрачности, что разрешено текущим форматом (ограничение старого Unity-конвертера на один primitive здесь не применяется).

**Godot4.7.2.stable.official.ed1daf0bf:** GLTFDocument.append_from_file и generate_scene успешно импортировали все3файла в отдельном проверочном проекте. У каждого один MeshInstance3D с масштабом1; AABB совпали с таблицей. Импортированные StandardMaterial3D сохранили emission у металла и стержня, прозрачность у стекла. Рендеры проверены визуально в Blender; запуск игровой сцены и её освещение не менялись.

Фактическая стоимость Meshy: 3генерации×30 +3ремеша×5 = **105кредитов**. Каждое действие≤30кредитов, в рамках разрешения владельца. Повторная генерация крышки/колец не потребовалась.
