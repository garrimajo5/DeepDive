Один mesh и один материал на файл, текстура base color 1024² внутри каждого GLB. Ухо дополнительно содержит 1024² emission mask. Каждый GLB меньше 1,9 МБ.

## Сборка в Godot

Метры, Y вверх. **Голова +Z**, правый бок −X — исключение из общего правила ARTIST.md по прямому требованию issue. Корень тела при стоянии на дне размещать на Y = 0,7: локальный низ лап −0,7. Длина сборки около 3 м, высота в покое около 1,48 м. Стебли и полые чаши — одна сетка каждого уха.

- Левое ухо: `(0.23, -0.02, 0.60)`.
- Правое ухо: `(-0.23, -0.02, 0.60)`, зеркало по X **на дочерней сетке**, а не на поворотном родителе.
- Центр мешка: `(-0.03894, -0.39648, 0.98722)`; масштаб от 0,9 до 1,1 вокруг этого центра.
- Шарнир челюсти: `(0, -0.305, 1.15)`; ось шарнира X.
- Оси ушей: ухо в покое открыто вверх +Y. Родитель поворота по Y, его дочерний узел наклона по X, затем сетка. Диапазоны из задания: Y ±130°, X −20…+63°. В основании есть скрытая округлая опора, вращающаяся вокруг фиксированного центра.

Координаты временных фигур из `echo_view.gd` не подходят новой сетке: использовать координаты выше. Временная воронка в коде направлена иначе; при интеграции учитывать именно +Y у поставляемого GLB. Код игры в этой ветке не изменён.

Для листа ракурсов использованы yaw/tilt −30°/+20° и +50°/−15°. Это демонстрационная поза, не ограничение диапазона.

## Свет и палитра

Основная кожа #344A59 и #667A87, костяные полосы #B5B5A5, поры #142B35; свет #67DDEB только в части глубоких внутренних складок уха. Маска учитывает внутренние грани, положение ниже края и тёмные пиксели; сила emission 0,12. Тело, мешок и челюсть не излучают свет. Тёмные точки головы — поры, глаз нет. Материалы неметаллические, roughness 0,86. Полосы — текстура, не отдельная геометрия.

## Генерация и обработка

Meshy CLI 0.4.0, image-to-3D, model type `standard`, текстура включена, PBR-карты отключены, исходная текстура 2k, выход GLB. Текстовый prompt не передавался: генерация по двум подготовленным изображениям из принятого ART-007. `src/body-reference.jpg` и `src/ear-reference.jpg` — уменьшенные копии входных референсов. Тело на референсе без ушей, вторая картинка изолирует одну полую воронку на стебле. Эти изображения подготовлены встроенным ImageGen на основе принятого концепта; не новый самостоятельный дизайн.

Remesh topology triangle. Фактическая стоимость Meshy: 30 + 30 + 5 + 5 = **70 кредитов**. Дополнительных платных генераций не делалось.

Blender 4.5.9: сварка совпадающих вершин, снижение геометрии тела, выделение мешка и челюсти, закрытие деталей, внутренняя подкладка горла, выпрямление уха вверх, сужение основания, установка pivot и метров, уменьшение текстур до 1024², создание маски свечения и экспорт GLB. Подкладка остаётся внутри корпуса и не является вторым анимируемым мешком. В `src/` сохранены рабочие скрипты и численные результаты; для полного повторения обработки сначала нужны исходные Meshy GLB по task ID и импортированные `body-raw.blend` / `ear-raw.blend`. Скрипты отражают рабочую структуру каталогов, это не автономный генератор исходной модели.

## Проверки и ограничения

Godot 4.7.2: все четыре GLB загружены через GLTFDocument, создана сцена, подтверждены по одной поверхности и base color 1024². Свечение включено только у уха. Лог — `src/godot-check.log`. Отдельно проверены размеры файлов, число треугольников, масштаб узлов, отсутствие skin/animation. Ракурсы собраны из повторно импортированных конечных GLB.

Внешний вид проще концепта: крупные грани складок, текстурная детализация камуфляжа местами мягкая; мешок небольшой и спрятан под горлом. Пальцы связаны со стопами, самостоятельных подвижных пальцев нет.

**Известное ограничение:** при одновременно встречном наведении двух ушей на крайние yaw раструбы пересекаются. Каждый шарнир допускает заявленные углы, но для пары потребуется согласованное наведение, либо последующая правка формы/разноса. Это не скрытое ограничение диапазона; пересечение показано на дополнительном листе проверки. Проверка выполнена вне игровой сцены; окончательная настройка материала в подводном освещении и поведения остаётся интегратору.
