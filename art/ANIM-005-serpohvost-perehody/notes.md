# ANIM-005: проверка тайминга, не сдача
Issue #1766. База origin/main9123b7b. Принятый исходник models/serpohvost-anim.glb, ANIM-001/PR654. Разрешение владельца13.11 на60 кадров/с передано в #1804. Геометрия, материалы, скелет и старые клипы не изменялись.

src/timing_bound.py воспроизводит необходимую оценку для непрерывно гладкой вертикальной траектории: если верхняя точка +0,3м достигнута в0,35с со скоростью0, то для достижения−0,8м в0,55с при |a_y|≤60 минимальная скорость вниз в0,55с составляет7,101м/с. За оставшиеся0,35с максимально возможный подъём с торможением до нулевой скорости —0,38472м вместо необходимых0,8м. Самая ранняя возможная остановка в нейтрали —0,95356с. Векторный предел ускорения не слабее вертикального.

Это НЕ доказательство невозможности заказа при любом прочтении: пик замаха может быть раньше0,35с, а заказ нормирует дискретные вторые разности. Это не Godot-замер и не готовая траектория. Вопрос заказчику — допускается ли более ранний пик при неизменных0,9с. Альтернатива — увеличить общую длительность с повторным подбором, оценка0,954с только необходимая, не достаточная для художественно пригодного движения.

### Обязательные настройки интеграции

При импорте поставить `animation/fps=60`; в расширенном импорте узла AnimationPlayer отключить `optimizer/enabled`. Образец параметров — `src/import-settings-example.txt` (пути/uid из временного стенда не копировать). При fps30 Godot теряет половину новых ключей; оптимизатор также удаляет малые изменения и искажает измеренную плавность. Ключ находится в настройках **узла AnimationPlayer**, а не отдельного клипа. Проверено на установленном Godot; структура настройки подтверждена [исходником импортера Godot](https://github.com/godotengine/godot/blob/master/editor/import/3d/resource_importer_scene.cpp).

Для Swim/SwimFast/Hover включить loop_mode=1 в настройках клипов: glTF сам флаг петли не хранит. Для разовых — без петли. Прежние каналы не перепекались. Переходы смешивает игра; GIF последовательности показывает сами клипы подряд без игрового crossfade и перемещения существа.
