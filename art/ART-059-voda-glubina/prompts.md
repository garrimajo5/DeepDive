# Поиск настроения — ImageGen
Четыре вертикальных панели одной подлёдной водной сцены: 8 м голубой #286B80; 20 м синий #1A4667; 45 м тёмный #0D2943 с малым холодным пятном прожектора; 90 м почти чёрный #05131F с узким пятном на песке. Без животных, объектов, текста, тёплых цветов, красного и сияющих стен; без серой засветки тумана. Результат — source/nastroenie.jpg.

Это источник атмосферы. Точная LUT построена отдельно по числам parametry.json, игровые пробы сняты в Godot без генеративной перерисовки.
