# ART-034 — заставка на время прогрева

Заказ #267. База `origin/main`: `f13e6d2873ec9ebea0d75f44d452e7b2f5957ce6`.

## Файлы
- `zastavka.jpg` — 2400×1080, пример состояния 50 % с названием и первой подсказкой.
- `zastavka-fon.jpg` — тот же кадр 2400×1080 без текста, полосы и интерфейса; 278 435 байт, меньше 1,5 МБ. Это единственная фоновая текстура для игры.
- `zastavka-sostoyaniya.png` — 2400×1440, состояния 0 / 50 / 100 %, четыре подсказки и границы кадрирования. Внутренняя голубая рамка — 16:9, наружная светлая — 19,5:9. Рамки только на пояснительном листе.
- `src/build.py` — воспроизводимая сборка надписей из готового фона. Требуется Pillow, первый аргумент — путь к DejaVuSans.ttf. Не изменяет код игры. Необязательный второй аргумент — исходное изображение для подготовки фона; третий — папка уменьшенных контрольных кадров.

## Компоновка
Начало координат — левый верхний угол; все размеры при 2400×1080. Шрифт **DejaVu Sans Regular**, поддерживает кириллицу. Используется обычное начертание без растяжения. Размеры шрифта ниже — пиксели, не пункты. Координаты текста относятся к верхнему краю видимых глифов (у Pillow anchor `lt`/`mt`); при переносе в Label учесть метрики шрифта.

| Элемент | Положение и размеры | Оформление |
|---|---|---|
| Название «Погружение» | x=360, y=416; область 760×126 | 104 px, #D5E4E8 |
| «Подготовка погружения» | x=364, y=574; область 560×48 | 34 px, #9AD9E8 |
| Проценты | правый край x=1020, y=574; область 100×48 | 34 px, #D5E4E8, по правому краю |
| Полоса | x=360, y=636, w=660, h=12; радиус 6 | трек #244955, заполнение #67DDEB |
| Подсказка | центр x=1200, верх глифов y=944; область x=560…1840, h=52 | 40 px, #D5E4E8, одна строка по центру |

Полоса заполняется слева направо: ширина `660 × clamp(Warmup, 0, 1)`. При 0 заполнения нет, остаётся трек; при 50 — 330 px; при 100 — 660 px. Проценты соответствуют фактической доле, не времени. При 100 подпись «Готово к погружению»; не задерживать готовую игру ради показа последней подсказки.

Подсказки меняются по очереди примерно раз в 8 секунд без дополнительного эффекта:
1. «Свайп — оглядеться»
2. «Крестовина — идти»
3. «Кнопка — действие у поста»
4. «Голосуйте у голостола: глубже или наверх»

Нижние углы свободны: при y>760 нет надписей в x<360 и x>2040. Для 16:9 также остаются свободными крайние 280 px отображаемого кадра. Никаких дополнительных кнопок, логотипов, мелких пояснений и мелкого текста в фоне.

## Другие экраны
Фон — один TextureRect, масштабировать с сохранением пропорций по высоте и обрезать симметрично по бокам; не растягивать. UI рисовать отдельными элементами поверх фона в той же системе координат.
- **19,5:9** при высоте 1080: видимая ширина 2340; обрезать по 30 px. Экранный x = x макета − 30.
- **16:9** при высоте 1080: видимая ширина 1920; обрезать по 240 px. Экранный x = x макета − 240. Корабль, название, полоса и все подсказки сохраняются целиком.
- Для фактической высоты H все значения умножить на H/1080. Общая формула: x экрана = x макета × H/1080 − (2400×H/1080 − W)/2; y экрана = y макета × H/1080. Подсказка остаётся по центру.
- Вырезы телефона: учесть safe area поверх этих отступов; не уменьшать шрифт ради выреза. Для нестандартных пропорций за пределами 16:9…20:9 потребуется отдельная проверка.

## Образ и источники
Утверждённый мир `docs/world.md`; корабль ART-001 (`kovcheg-7.md`, `kovcheg-7-nad-rifom.jpg`), семья интерфейса ART-028 (`sbor-ekipazha.md`). Собственная встроенная генерация по принятому кораблю, затем уточнение ориентации: хвост выше слева, нос ниже справа, прожектор уходит во тьму. Все надписи и полоса набраны отдельно кодом художника, в исходном фоне их нет.

Корабль — прежняя 32-метровая сигара, охристый металл, панорамное носовое окно, два окна ближнего борта, кольцевой ротор и носовой манипулятор. Дальний симметричный ротор скрыт корпусом. Новых сюжетных объектов, людей, чудовищ, врат и светящегося поля не добавлено. Для модели используется существующая сборка ART-001; эта заставка — плоская иллюстрация, новых 3D-деталей не требует.

Палитра: интерфейс #67DDEB / #9AD9E8 / #D5E4E8, глубина #0B1C24, трек #244955; лёд #86BCCB, охра корабля #8C806B, тёплые окна #F6DEAC. Красных огней нет. В игре анимируется только заполнение полосы и сменяется подсказка; фон неподвижен.

## Проверка и авторские решения
Проверены размеры, вес файлов, кадрирование и читаемость на уменьшенных вариантах 960×540 (16:9) и 1170×540 (19,5:9). Все четыре подсказки помещаются в одну строку; на этих растрах название 52 px, подсказка 20 px. На физическом телефоне 6 дюймов не проверено — это ограничение проверки, проверить при интеграции.

Авторские решения: корабль справа, место названия слева, крупные простые надписи и тонкая полоса, приглушённый риф внизу как край Подлёдного сада. Общая композиция соответствует погружению под лёд, без рекламного слогана. Риф и вода — художественная подложка, не точная геометрия текущей игровой сцены. Код Warmup и сцены не менялись.
