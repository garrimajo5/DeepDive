Godot 4.7.2 под Android. Цели, аудитория, роли и кто что решает — **`docs/PASSPORT.md`** (утверждён владельцем
07.11.2026). Этапы пересобраны владельцем 07.11.2026: у каждого есть критерий готовности (DoD). Этап закрыт, когда
владелец принял DoD и закрыл milestone; приёмку готовит проект-менеджер. Этапы — milestones «Этап N» в GitHub, задачи —
эпики по этапам, где мы сейчас — issue #645 «Где мы»; история сделанного по шагам до 25.10 — `ROADMAP.md`.

**Порядок (решение владельца 07.11.2026):** этап 3 доводим параллельно с этапом 4; затем слой 1 в одиночку (этап 4),
потом вдвоём (этап 5). Этапы 6 и 7 до этого не берём, кроме багов. Работа вне DoD текущего этапа — не больше 20 %
времени роли (паспорт, «Правило фокуса»).

**Вся игра — кампания** (решение владельца 27.10.2026, #635): один «Ковчег-7», сохранение, гибель → загрузка, без
отдельных повторяемых забегов; слои подряд, в конце — одна из концовок. Сессия — 1–2 часа за раз.

Главные риски: управление с телефона, стоимость 3D-контента, сетевой кооп на мобильных, поиск игроков. Каждый риск
сначала проверяем дёшево — пробой в одну PR.
