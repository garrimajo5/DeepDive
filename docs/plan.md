# Поэтапный план «Погружения»

Расчёт на одного разработчика с частичной помощью художника и звукорежиссёра. На каждом этапе есть контрольная точка: дальше идём, только если она пройдена.

| Этап | Срок | Цель | Контрольная точка |
|---|---|---|---|
| 0. Проверка идеи | 1–2 нед. | Прототип на GitHub Pages, игра на Android, отзывы 3–5 человек | Люди сами хотят плыть дальше и изучать существ |
| 1. Геймплей в браузере | 1–2 мес. | Полный забег по отмели: брифинг, спуск, события, образцы, «глубже или наверх»; новые отсеки; 15–20 видов | Забег на 20–30 минут, который хочется повторить |
| 2. AR на телефоне | 1 мес. | WebXR: мостик на реальном столе, иллюминаторы на стенах | В AR интереснее, чем на экране; иначе AR остаётся бонусом |
| 3. Кооп на 2 телефонах | 1–1,5 мес. | Сервер синхронизации, общий маркер, голос | Двое переговариваются и выживают только вместе |
| 4. Решение | 1–2 нед. | Видео и отзывы, формат проекта, команда, устройства (Quest 3, iPhone) | Решение идти в большой проект |
| 5. Unity, вертикальный срез | 3–4 мес. | Unity 6 + URP, AR Foundation, Meta XR SDK, Photon; отмель в финальном качестве | Трейлер-срез для издателя и страниц магазинов |
| 6. Контент | 6–9 мес. | Пять слоёв, ~100 видов, загадки Хранителя, кампания, удалённые игроки, смешанные сессии Quest + телефоны | Игра проходится целиком |
| 7. Тесты и полировка | 2–3 мес. | Разные комнаты, слабые телефоны, обучение, локализация, бета | Стабильная бета |
| 8. Ранний доступ | — | Meta Horizon Store, Google Play, App Store, Steam; сообщество; обновления | Выход |

Итого: прототип на 2–4 игрока за 4–6 месяцев почти без затрат, полная игра — ещё 12–18 месяцев командой из 3–4 человек.

Главные риски: удобство AR в реальных комнатах, дрейф общих якорей, стоимость 3D-контента, поиск игроков для коопа. Каждый крупный риск сначала проверяется дёшево в браузере (этапы 2–3).
