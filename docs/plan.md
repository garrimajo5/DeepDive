# Поэтапный план «Погружения»

Godot 4.7.2 под Android. Расчёт на одного разработчика с помощью художника (Codex). На каждом этапе есть контрольная точка: дальше идём, только если она пройдена. Этапы — milestones «Этап N» в GitHub, задачи — эпики по этапам, где мы сейчас — issue #645 «Где мы»; история сделанного по шагам — `ROADMAP.md`.

| Этап | Цель | Контрольная точка |
|---|---|---|
| 1. Каркас | Мостик, штурвал, ход корабля, отмель, APK на телефон | Корабль удобно вести с телефона, сцена держит частоту кадров |
| 2. Корабль | Отсеки, посты (сонар, энергия, сканер), прожектор, приборы, корпус снаружи | Все четыре роли можно сыграть одному, переходя между постами |
| 3. Живая отмель | Экосистема: стаи, мох, пасущиеся, хищники; образцы и шлюз | На отмели интересно плавать и наблюдать без задания |
| 4. Забег | Брифинг, спуск, события (пробоина, перегрев, сонарная тьма, чужой голос), «глубже или наверх», сохранение | Забег на 20–30 минут, который хочется повторить |
| 5. Кооп | 2–4 телефона по сети, роли у разных игроков, голос | Двое переговариваются и выживают только вместе |
| 6. Контент | Пять слоёв, ~100 видов, загадки Хранителя, кампания | Игра проходится целиком |
| 7. Тесты и выход | Слабые телефоны, обучение, бета, Google Play | Стабильная бета |

**Решение владельца 27.10.2026: вся игра — кампания** (#635): один «Ковчег-7», сохранение, гибель → загрузка, без
отдельных повторяемых забегов; слои подряд, в конце — одна из концовок (#110). Механики этапа 4 (брифинг, события,
«глубже или наверх», сохранение) остаются частями кампании; контрольную точку этапа 4 переформулирует владелец (#633).

Главные риски: управление с телефона, стоимость 3D-контента, сетевой кооп на мобильных, поиск игроков. Каждый риск сначала проверяем дёшево — пробой в одну PR.
