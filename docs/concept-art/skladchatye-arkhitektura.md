## Заметки художника (суть)
Числа — ориентир для блокаута, а не обмер перспективы; брать из таблицы, не по пикселям. Оси Godot, метры.

| № | Элемент | Размеры | Из чего собрать |
|---|---------|---------|-----------------|
| 1 | Дуги и пустоты | пролёт 6, толщина ≈ 0,35 | 3 повторённых изогнутых конусных сегмента + неровная основа (4 части), статически |
| 2 | Контактная тройка | чашки Ø 0,4, глубина 0,1; центры (−1,2; 0; 0), (1,2; 0; 0), (0; 2,078; 0) — шаг 2,4 | 3 чашки + участок стены; плоскость наклоняется целиком |
| 3 | Насесты | высоты 0,6 / 1,5 / 2,7, разброс ≈ 4,2, треугольником, не в ряд | 3 сужающихся изогнутых столбика с впадинами |
| 4 | Борозды 3–1–3 | ложе 3, канавки 0,08 → одна 0,16, глубина 0,02–0,04 | одна статичная сетка, шероховатость в текстуре |
| 5 | Клапан | чистый проход Ø 3 | горловина + 3 асимметричные створки (4 части) |
| 6 | Письмо | участок 1,2 × 0,8, рельеф 0,02–0,04 | основа + 5–7 ветвящихся рёбер; заряд — маска для сканера |
| 7 | Тройной рубчик | ≈ 0,12 | 3 выпуклых рубца + основа |
| 8 | Водовод и лаз | просвет Ø 18, прямой участок ≥ 48; лаз 2,2 × 2,6 | 3–4 незамкнутые оболочки + боковая горловина |

- Металла нет, шероховатость 0,8–1, emission 0 у всей архитектуры. Ни дуги, ни гнёзда, ни клапаны не светятся.
- Палитра: #0B1C24 вода и пустоты, #283638 основание, #747C70 дуги, #B8BAA6 блики, #655665 мягкие участки,
  #567664 несветящиеся обрастания и купола; #67DDEB — только местная жизнь (и условный цвет данных сканера на листе).
- Сцена «сейчас»: тот же участок, что в прошлом, обросший местной жизнью; пролом закрыт несколькими перекрывающимися
  купольниками (≈ 4 м каждый, по бестиарию) — слоистая заплата, не одна плёнка и не возврат к гладкой поверхности.

## Решения и привязка к игре
- Размеры из таблицы — рабочие числа для ART-020 и блокаута лаборатории; шаг гнёзд 2,4 м и Ø 0,4 м — из ART-018,
  поменять их может только владелец.
- **Клапан:** анимация — три отдельные створки поворачиваются вокруг наружных креплений с небольшим сдвигом, узел
  целиком не масштабировать. Ритм «короткий · короткий · длинный» (0,15 / 0,2 / 0,15 / 0,6 / 0,6 с) — предложение
  художника для схемы, **не** утверждённая загадка: механику открытия решают вместе с разрядом корабля (поток А,
  `zap.gd`) отдельной задачей. В мире у клапана нет ни схемы, ни ламп, ни подсветки.
- **Письмо:** рельеф — геометрия меша (её видит сонар), заряд — отдельная маска (её показывает сканер биолога),
  у стены emission 0. Голубые точки листа — только условный цвет прибора. Расшифровку и текст не выдумывать (#110).
- **Тройной рубчик:** тот же знак, что метка лабораторных серий на существах (ART-023), но у существ — живая ткань.
  На касание три рубца приподнимаются на 2–3 мм и возвращаются за 0,5 с, без свечения. Дальний вариант — в текстуре,
  анимируемый близкий — отдельным мешем.
- **Водовод:** «Ковчег-7» (32 м) проходит канал Ø 18 м, лаз 2,2 × 2,6 м ему закрыт — туда проходит только компактная
  складка (1,6 × 2 м). Проходимость подтверждать коллизиями модели корабля, когда лабораторию будут собирать.
- Купольники-заплаты — непрозрачные оболочки без многослойной прозрачности; декор объединять по материалам
  (бюджет < 260 вызовов отрисовки, < 350 тыс. треугольников).
- Освещение «прошлого» — условная архивная экспозиция, в игровой уровень как постоянный свет не переносить:
  в лаборатории светят только прожектор «Ковчега» и местная жизнь.
- В сцене гнёзда, борозды и клапан укрупнены для читаемости — для модели брать числа таблицы.
- Модели по листу пока не заказаны: сначала эскизы узлов лаборатории ART-020 (#117).
