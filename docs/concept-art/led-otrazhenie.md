## Решения и привязка к игре
- Приёмка: файлы просмотрены. На мели у горизонта лёд темнее и холоднее — читается как гладь воды снизу, сверху светлое
  окно с прежними трещинами; граница мягкая, на 30 м эффект слабый, на 45 м почти незаметен. Эффект сдержанный —
  на телефоне в Forward Mobile проверить, что «зеркало» читается; при необходимости поднять `reflect_gain`.
- **Встройка в `shaders/ice.gdshader`** (тот же `OceanView.ice`, слой `LAYER_WORLD`, 0 новых вызовов, ≤ 2 новые выборки):
  ```text
  wn = мировая нормаль ART-056 (или (0,-1,0) без рельефа)
  mu = clamp(dot(wn, normalize(camera - world)), 0, 1)
  smooth = texture(maska, world.xz/16).r                     # выборка 1
  lookup = clamp(mu_c + (mu - mu_c) * mix(.35, 1, smooth), 0, 1)
  mirror = texture(lut, ((255*lookup+.5)/256, (row(depth)+.5)/16))   # выборка 2
  open = smoothstep(.10, .55, crack * gate)                   # трещины пропускают, не зеркалят
  a = mirror.a * (.30 + .70*smooth) * (1 - open) * reflect_gain * (1 - silt_k)
  ALBEDO *= 1 - a
  EMISSION = glow_color*(glow_base*(1-a) + glow_crack*crack*gate)*glow_k*glow_gain + mirror.rgb*a
  ROUGHNESS = mix(roughness, .20, a*smooth)
  ```
  `row(depth)` — кусочно-линейно по ключам 0/8/20/45/90 м, глубина — `main.helm.depth()`. Затухание уже в A — **не умножать**
  ещё на `exp(-depth/9)`. Свечение трещин не ослабляется, шахты ART-052 и каустики не меняются.
- Отражение подаётся в EMISSION (не освещается «солнцем» второй раз); не Light3D, не SSR, без второй камеры и
  ReflectionProbe. Без TIME и шума по кадрам — граница дрожит только от нормалей ART-056 и поворота камеры.
- **Ил главнее:** `a *= 1 - silt_k`, в густом иле отражения нет.
- **«Экономно» (ART-044):** маску не читать, `smooth = 0,55` константой, `a *= 0,55` — одна новая выборка.
- Палитра холодная (`#204D5B` у поверхности → `#04101B` на 90 м), без тёплого и красного (#129).
