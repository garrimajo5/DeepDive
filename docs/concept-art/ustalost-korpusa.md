# «Корабль устал» внутри: потёки, капли, искры, пар (ART-074)

Заказ #513, принято 23.10.2026 (PR #515, ветка `art/ART-074-ustalost-korpusa`).

- `ustalost-maska.png` — RGB8 512², бесшовная плитка 1×1 м, **линейные данные (без sRGB)**: R — тонкие вертикальные потёки,
  G — мокрые пятна пола, B — порог **потери** прочности (≈ 0,37…0,77).
- `ustalost-atlas.png` — RGBA8 512², 4×4 по 128² (поле 12 px прозрачное), **прямая альфа**: 0–3 капля с хвостом, 4–7 короткая
  искра, 8–15 тонкий шлейф пара. Слева направо, сверху вниз.
- `ustalost-list.png` — мостик при 70/40/15 %, машинное при 15 %, схема мест по постам; `ustalost-proverka.png` — атлас на
  шахматке, каналы маски, искра у пульта, конденсат и пар, «Экономно»; `ustalost-mostik-15.jpg`, `ustalost-mashinnoe-15.jpg` —
  игровые кадры примерки при 15 % (Vulkan, Forward Mobile).

## Решения и привязка к игре
- Приёмка: файлы просмотрены. При 70 % сухо, при 40 % первые потёки, при 15 % корабль явно «устал», окна, экраны, щиток
  и посты чистые, без красного (#129), не похоже на пробоину. Круглое пятно в машинном (правка 1) — остаток старого
  `CPUParticles3D` пара до #511 на основе примерки `138e7e8`; на текущем `main` этого узла нет (пар ART-071 — MultiMesh).
- Вход: `loss = clamp(1 − Vitals.hull/100, 0, 1)` (как ART-049); маска — `gate = smoothstep(B, B + 0,14, loss)`; при встройке
  вход сгладить за 0,3 с. Ремонт идёт обратно по тому же весу: искры → пар → капли → сухие стены, отдельных таймеров нет.
- Пороги частиц: капли `S(0,38; 0,82; loss)` (с 62 %), пар `S(0,48; 0,85)` (с 52 %), искры `S(0,62; 0,86)` (с 38 %).
  При `hull ≥ 62` MultiMesh скрыт целиком.
- Потёки и пятна — в существующем `ship_surface.gdshader` (0 новых вызовов) по `BridgeView.planar_uv`, 1 UV = 1 м:
  ALBEDO × `1 − 0,68·amount`, roughness → 0,24 с весом `0,72·amount`, clearcoat `0,7·amount`, без эмиссии. Amount: R — на
  стенах сверху (гаснет к низу y 2,85…1,35), R × 0,6 — на потолке у бортов, G — полоса пола 0,8 м у бортов (центр прохода сухой).
  Только мостик (z < 2) и машинное (z 14…19,5); у переднего окна чистая рамка (z −5,7…−5,35). Вокруг семи постов карта гаснет:
  радиус 0,8 м, переход до 1,25 м (штурвал (0; −4,2), энергия (−3,9; −2), сканер (3,85; −2), сонар (0; −1,2), разряд (−3,9; −0,5),
  вентиль (−2,2; 17,2), щиток (2,2; 17,2) в x/z). Приборы, стекло, реактор, модели и плафоны карту не получают.
- Частицы — **один MultiMesh** (один QuadMesh, один `ShaderMaterial`, билборд, тени выкл, слой `OceanView.LAYER_SHIP`),
  24 карточки (12 на «Экономно», по 3 в группе): капли мостика x ±4,66, z −4,65 / +0,8 (левая, мимо щитка разряда) / −0,35 (правая) / 1,2;
  капли машинного x ±2,72, z 14,7 / 15,4 / 18,8 — падают с y 3,05 до 0,25, цикл 3,8 с, карточка 0,028×0,12 м, альфа
  `0,8·сила·sin(π·age)`, фазы через 1,713 с; искры — пакет 6 карточек раз в 9 с у `(−4,58; 0,38; −0,98)` за фронтом пульта
  энергии, жизнь 0,16 с, 0,18×0,07 м, эмиссия RGB × 1,2 (#FFF2D5 → #E7C28B), без Light3D; пар — у `(−2,92; 1,58; 17,2)` над
  корпусом вентиля, цикл 3,8 с, подъём 0,48 м, снос ≤ 0,12 м, размер 0,12×0,26 → 0,25×0,56 м, альфа `0,11·сила·sin(π·age)`,
  эмиссия 0. Кадры смешивать в премультиплированном виде, не переходя между группами.
- Бюджет примерки: +0 вызовов на потёки, +1 на частицы, 0 новых огней. Справочная примерка шейдера — `src/surface.gdshader`,
  `src/particle.gdshader` в коммите `b5a93fd` ветки PR #515. Маску и атлас копировать в `textures/` при встройке (`docs/` не
  импортируется). Встройка — задача ROADMAP потока А.
