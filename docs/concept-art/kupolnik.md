# ART-081 — Купольник, рабочий Хранителя (принято)

Принятый концепт: `kupolnik-rakursy.png` (сбоку, спереди, сверху, купол, захват и сифоны крупно, габарит, сравнение
длин с «Ковчегом-7» — 40 px = 1 м) и `kupolnik-stvorka.png` (подушки захвата, клапан-сифон изнутри, поза у контактного
гнезда террасы врат ART-079 — поднимает створку на 1,4 м). Исходник — `docs/world.md` (раздел 5: Хранитель вспышками
командует купольниками), материал — `warden.jpg`, гнездо и створка — `terrasa-vrat.md`.

## Заметки художника (кратко)
Низкий продолговатый минеральный купол с широкими продольными рёбрами, под ним мягкое мускульное тело, три захвата
с парными листовидными подушками, сзади два коротких сифона с тремя складками клапана. Без спирали, лица, шарниров
и инструментов. Родство с Хранителем — только матовый фиолетовый минерал и овальные голубые фотофоры.

| Параметр | Размер |
|---|---|
| Габарит в покое (длина × ширина × высота) | 3,0 × 1,8 × 1,2 м |
| Купол | 2,2 м |
| Гибкая часть захвата / пара подушек | ≈ 0,75 м / ≈ 0,45 м |
| Устье сифона | ≈ Ø 0,25 м |

Плывёт медленно: втягивает воду нижней мантийной щелью, выталкивает задними сифонами; поворот — разницей клапанов;
захваты при плавании собраны под куполом. У гнезда: один захват держит обод, второй поднимает створку по направляющей
(скольжение, не дверца), третий свободен и не закрывает ямки; потом отпускает, разворачивается и уходит.
Фотофоры `#67DDEB` по кромке купола: в покое слабо, команда Хранителя — короткий общий импульс. Палитра: купол
`#544773`, рёбра `#827DA0`, мягкое тело `#655870`, углубления `#302C45`, вода `#0B1C24`. Матовый, metallic 0.

Модель: ≤ 8000 треуг. (купол 2400, мантия 800, захваты с подушками 3000, сифоны 1000, резерв 800), одна skinned mesh,
один материал, атлас 1024² + нормали/шероховатость, маска emissive на том же UV, без отдельных ламп. Скелет ≈ 20
костей: Root → Body; на каждый захват Upper → Lower → PadA/PadB; на сифон Base → Valve; две кости мантии. Клипы
(30 fps, на месте): `Swim` 3 с цикл, `OpenPetal` 5 с разовый, `Idle` 4 с цикл. GLB: Y вверх, перед −Z.

## Решения и привязка к игре
- **Принято как основа модели** купольника (следующие заказы — MOD по этому листу, затем ANIM на три клипа).
  Размеры — из таблицы, не из перспективы листов.
- **Расположение захватов — по видам сверху и спереди**: три корня поперечным веером под передней кромкой купола.
  На виде сбоку они нарисованы вдоль тела — это неточность генерации, в модель не переносить.
- Створка — часть террасы (ART-079, свой pivot), не купольника; её ход синхронизирует сцена места 07, не скелет.
  На листе 02 створка нарисована овальной — форму брать из `terrasa-vrat.md` (1,7 × 1,5 × 0,12 м).
- **Код — поток Б** (#837): модуль мира купольника — выход к гнезду, `OpenPetal`, уход сифонами; импульс фотофоров —
  параметр emissive материала. Что значит открытая створка для корабля — событие через `EcoLink`, вторая сторона —
  поток А. Значения команд Хранителя и сюжет не задаются — решает владелец.
- Первое впечатление — полезный, но чужой: не нападает, к кораблю не тянется, на прожектор не реагирует.
