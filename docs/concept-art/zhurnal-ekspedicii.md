## Решения и привязка к игре
- Отдельный экран между забегами, пункт меню «Журнал экспедиции» после «Экипаж» (ART-037); органы управления
  скрыты. Контент 1680 px по центру: L = (W − 1680)/2, R = L + 780 (2400 — 360/1140, 2340 — 330/1110, 1920 —
  120/900), масштаб H/1080, кегли и кнопки не сжимаются.
- Заголовок (L, 65) 56 px; «Назад» (L + 1380, 52) 300×112. Карта (L, 270) 730×570, север −Z вверх, точка места
  u = L + 365 + 1,25·x, v = 560 + 1,25·z (`Run.PLACES`, 1 px = 0,8 м); иконка 80×80 в кнопке 112×112; посещённое —
  контур #67DDEB и галочка. Касание — название под картой, забег не начинает.
- Сводка с x R + 64, y 219 + 67·i, 36 px, иконки ART-026 48 px. Знаменатели — настоящие: видов — `Species.count()`
  (не навечно 100), образцов — без «из 24», пока ёмкость трюма не утверждена (`HoldShelves` — 24 банки).
- Сетка 3×2: ячейка 280×160, шаг 300×180 от (R, 550), порядок каталога видов; «?» не раскрывает имени, касание —
  «Изучите вид сканером». «Ранее» / «Далее» 240×112 (y 922), номер страницы по центру; на краях неактивны.
- «Новое» — плашка 139×39 в ячейке, снимается только открытием карточки (нужен список прочитанных).
- Карточка 1320×715 по центру, картинка 500×230 слева, текст — `Lab.card_lines`, «Закрыть» 360×112; системный
  «Назад» сначала закрывает карточку.
- **Чего нет в сохранении** (`SaveGame` v1: груз, поднятые, изученные и наблюдения): посещённые места, число
  забегов, рекорд глубины, прочитанные карточки — добавить в формат при встройке; для старого сохранения — «—» и
  «История посещений ещё не записана», не выдумывать. Повреждённый файл — своё сообщение, не «первый запуск».
- «Дальше: <место>» — только непосещённое доступное место по настоящей истории.
- Палитра ART-028, DejaVu Sans, ничего красного и янтарного. Встройка — задача ROADMAP потока А (после меню ART-037).
- Полные координаты — в истории PR #339 (`art/ART-047-zhurnal-ekspedicii/notes.md`).
