# MOD-019 — атлас надписей табло тревог (#198)

Принято из PR #225 (ветка `art/MOD-019-tablo-atlas`, художник Codex). Заменяет рантайм-шрифт на табло тревог ART-025.

## Решения и привязка к игре
- Игровая текстура: `textures/tablo/trevogi-slova.png` — маска 2048×256, L, значения ровно {0 фон, 128 углы, 255 буквы}.
  Импорт без потерь, без mipmap, без 3D-сжатия (`detect_3d/compress_to=0`), иначе мелкие буквы (~9,5 px) мылятся.
- Шейдер `shaders/alarm_board.gdshader` берёт покрытие букв из класса 255 (`smoothstep(0.6, 0.9, r)`); углы полей
  рисует сам (геометрия), поэтому класс 128 из маски намеренно отбрасывается. Цвета — из кода (`WORD_OFF`/`WORD_ON`
  = #66747A / #FFB259), совпадают с палитрой заказа, поэтому цветные атласы художника в игру не берём.
- UV U растёт слева направо при взгляде с кормы на нос; «ПРОБОИНА» у левого борта. Границы полей — `AlarmBoard.field_span`,
  совпадают с `fields.json` заказа (0 / 299 / 939 / 1266 / 1735 / 2048 px).
- Проверено в Godot: табло над носовым окном, четыре поля горят янтарным с уголками, «ПРОБОИНА» погашена серым —
  все пять надписей читаются (скриншот приёмки). Читаемость на физическом телефоне в движении — за тестером.
- Полный исходник заказа (цветные атласы on/off, маска, воспроизводимый `build_atlas.py`, `notes.md`, `fields.json`)
  — в истории ветки `art/MOD-019-tablo-atlas`. Превью приёмки — `tablo-atlas-mod019-preview.png`.
