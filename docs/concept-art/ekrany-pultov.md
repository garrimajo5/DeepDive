# Экраны пультов у штурвала (ART-061)

Заказ #427, принято 10.11.2026 (PR #433, ветка `art/ART-061-ekrany-pultov`, сдача v7). Компоновка центрального
экрана — по решению UX в #1402 (10.11): подписей над числами нет, глубину и курс различают единицы «м» и «°», лента
компаса под курсом заменяет подпись.

- `ekrany-pultov-atlas.png` — атлас RGBA 1024×512, 19 КБ: фоны и неподвижная разметка трёх экранов (верхняя полоса
  y 0…136) и банк глифов (строка y 384…448, ячейки 64×64: `0–9 . м ° / − с`; глифы — белые по альфе).
- `ekrany-pultov-kadr.jpg` — концепт 1600×720 с места пилота (контрольные 120 м / 245°; HUD показывает настоящие 20 м / 0°).
- `ekrany-pultov-2400.jpg` — тот же кадр 2400×1080, руль 0.
- `ekrany-pultov-povoroty.jpg` — контрольный лист: центральный экран при руле 0, ±0,2, ±0,4, ±0,8 в 1600×720 и 2400×1080.

## Решения и привязка к игре
- **Приёмка:** кадры просмотрены целиком и крупно. «120 м» и «245°» с единицами видны при руле 0 в обоих разрешениях;
  при повороте кисти цифры не закрывают, по цифрам проходит только спица (исключение UX, #1402 п. 4в). Лента компаса
  при руле 0 видна целиком. Красного нет (#129), тревога — янтарь #FFB259. Свечение слабое (EMISSION = цвет × 0,15) —
  bloom не пересвечивает. Карта 19 КБ ≤ 512 КБ.
- **Бюджет** (замер художника, desktop Vulkan Forward Mobile, main 330f2ff): 14 пар кадров — 106 → 106 вызовов; один
  атлас в существующий материал экранов, без мешей на цифры. Телефон не проверен — замер при встройке.
- **Раскладка атласа:** ход — [0, 0, 320, 136]; глубина и курс — [352, 0, 672, 136] (пустой тёмный фон); свет/сонар —
  [704, 0, 1024, 136]. Палитра: #0B1C24, #173B48, #315C68, #507E88, #67DDEB, #FFB259.
- **Координаты встройки** — в пикселях панели 320×136, UV панели = (x / 320, y / 136):
  - глубина: цифры x 75 / 88 / 101, y 4, 13×66; «м» x 115, y 24, 11×34;
  - курс: цифры x 204 / 217 / 230, y 4, 13×66; «°» x 244, y 4, 10×34;
  - безопасные окна по u: глубина 0,2344…0,3938, курс 0,6375…0,7938 (#1402 п. 3) — ничего выше верха цифр;
  - цифра берётся из внутренней части ячейки [12, 0, 52, 64]; единицы — плотные прямоугольники атласа: «м»
    [716, 397, 756, 435], «°» [789, 393, 811, 417] (единица не мельче половины цифры);
  - компас: x 204…254, деления y 64…73, указатель x 229, y 58…63; шаг 8 px на 10°, сдвиг `mod(курс, 10) · 0,8`;
    не ниже нижних 12 % панели;
  - ход (левый экран): цифры x 95 и 141, y 40, 30×58; точка x 126, 14×58; «м/с» x 186 / 207 / 226, y 56; знак заднего
    хода — глиф «−» (14) в резерве x 64, y 40, 24×58 — **обязателен** при отрицательном ходе. Левый экран частично под
    руками и крестовиной — точный ход остаётся в строке приборов;
  - свет/сонар: кольца (282, 28) и (282, 100); заполнено — включено/готов, контур — выключено; пинг — мягкая пульсация.
- **Значения:** курс = `wrap(−rad_to_deg(yaw), 0, 360)`, глубина = `−pos.y`, ход = `Helm.Ship.speed` с одним знаком.
  Контрольные 120 м / 245° из пробы не переносить.
- **Питание и помехи:** `Vitals.screen_k` (k.x/y/z — свой пульт) умножает фон и числа вместе, 0 — экран погас; при
  помехах случайных чисел не рисовать. Тревога — мигает рамка или малый индикатор янтарём, не поле цифр.
- **Проба художника** (не игровой код): `src/preview-v7.gdshader`, `src/capture-v7.gd` в ветке PR #433 (коммит `843b946c`,
  до удаления папки) — материал `ALBEDO = цвет · 0,55 · k`, `EMISSION = цвет · 0,15 · k`, геометрия экранов в осях модели:
  левый x −1,03…−0,59, y 1,03…1,22; средний x −0,36…0,36, y 1,02…1,32; правый x 0,59…1,03, y 1,03…1,22.
- Встройка — поток А, #1568: `shaders/console_screens.gdshader`, `BridgeView.set_screens`.
