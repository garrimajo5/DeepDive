# Стекло носовых окон (ART-057)

Заказ #413, принято 22.10.2026 (PR #418, ветка `art/ART-057-steklo-okon`).

- `steklo-maska.png` — RGBA 1024×512 на одно окно, данные без sRGB: R — муть у рамы, G — высохшие капли и разводы,
  B — редкие царапины, A — общая сила (0,85R + 0,55G + 0,45B, не выше 0,9). Не бесшовная, края — у рамы.
- `steklo-normali.png` — RGB 1024×512, OpenGL +Y: волна толстого стекла (0,8 мм на 2,5 м) и слабые царапины; repeat выкл.
- `steklo-kadr.jpg` — настоящий кадр Forward Mobile `z=-3 yaw=0` с пробным материалом; `steklo-sravnenie.jpg` — до/после
  с поста и у окна.

## Решения и привязка к игре
- Приёмка: файлы просмотрены, маска и каналы проверены; центр окна (56 % ширины и высоты) почти чистый — A ≤ 0,0023,
  существа и табло ART-025 читаются как без стекла; муть и капли — только у рамы; красного нет (#129). Эффект тонкий:
  итоговую силу подбирать на устройстве.
- Встройка — в имеющийся материал стекла (`BridgeView._add_glass`, общий `ShaderKey.glass`), тот же один квад и один
  вызов: альфа `0,07 + 0,26·A`; шероховатость `clamp(0,12 + 0,50R + 0,14G, 0,12, 0,70)`, specular 0,55, metallic 0;
  глубина нормалей 0,12 (на телефоне хватит 0,06). Рефракции экрана нет.
- Три окна одной картой: квад 7,6 × 1,9 м делить по u = 0,328947 / 0,671053, каждый участок нормировать к 0…1; средний
  отражён по U, правый — по V (на отражённых нормалях инвертировать R/G). Сдвигать UV с wrap нельзя — муть уйдёт в центр.
- Мигание `Vitals.lamp_k` гасит только отражение плафонов (множитель `0,15 + 0,85·lamp_k`), не альфу: грязь остаётся.
  Своей эмиссии у стекла нет; блики плафонов в центре окна ограничить, если ложатся на существ.
- «Экономно» (ART-044): без нормалей и динамического отражения, альфа `0,07 + 0,12·A`, шероховатость 0,6.
- Карты копировать в `textures/bridge/` (`docs/` не импортируется). Встройка — задача ROADMAP потока А.
