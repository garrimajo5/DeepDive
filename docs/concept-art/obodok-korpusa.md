# Ободок и затенение щелей корпуса снаружи (ART-076)

Заказ #525, принято 24.10.2026 (PR #529, ветка `art/ART-076-obodok-korpusa`; генератор LUT `src/build_gradient.py`, шейдер
примерки `src/hull-preview.gdshader`, съёмка `src/capture.gd`, кадры `source/*.jpg` и проверки `validation.json` — в истории ветки).

- `obodok-gradient.png` — LUT RGBA8 256×8, **линейные данные** (без sRGB, clamp, linear, без mipmap и сжатия с потерями).
  X — `e = 1 − dot(Ngeo, V)`, `U = (255e + .5)/256`; строки — глубина 0 / 8 / 14 / 20 / 32,5 / 45 / 90 м и ил (строка 7, A = 0).
  RGB — цвет воды ART-059, приподнятый в темноте; A = `depth_strength · e^3,2 · smoothstep((e − .15)/.8)`,
  `depth_strength` 0,22 / 0,32 / 0,48 / 0,82 / 0,58 на 0 / 8 / 20 / 45 / 90 м.
- `obodok-list.png` — три пары «с / без»: облёт 12 м, тот же ракурс 45 м (прожектор выключен), сзади-сверху на 8 м.
- `obodok-proverka.png` — LUT, кривые по углу, диагностический AO, повреждения 15 %, разряд, «Экономно».
- `obodok-45m.jpg` — полный кадр облёта на 45 м с ободком.
- `obodok-parametry.json` — строки LUT, коэффициенты, координаты зон AO.

## Решения и привязка к игре
- Приёмка: файлы просмотрены. На 45 м без прожектора край корпуса отделяется от воды мягкой синей кромкой, без
  неоновой полосы; на 12 м и 8 м эффект слабый. Стыки и примыкания чуть темнее, корпус не грязный. Дуги ART-068 и
  следы ART-049 на месте. На телефоне проверить, что кромка не мерцает на облёте.
- **AO — процедурный, без текстуры:** у `HullMesh` нет своей UV (обшивка ART-024 — трипланарная плитка 2 м), поэтому
  `ao-korpus.png` не сдан, это разрешено заказом. Швы — уже прочитанная `mask_tex` (0 новых выборок), примыкания — поля
  в метрах корабля (`lp`), берётся **max**, не сумма:
  - крепление двигателя `HullPlan.MOUNT`: центр `(±3,45, 1, 26,3)`, полуразмеры `(0,75, 0,225, 0,7)`,
    `exp(−max(boxSDF, 0)/.18)`;
  - ниша ротора: ось `(±5,4, 1, 26,5)`, `(1 − smoothstep(1,0, 1,29, ρ)) · exp(−((z − 26,5)/.72)²)`;
  - корень руля глубины `patch((±3,95, 2,6, 24,6), (.28, .30, 1,0))`, верхний стабилизатор `patch((0, 3,42, 25), (.28, .25, 1,3))`,
    нижний `patch((0, −.2, 25), (.25, .24, 1,1))`, где `patch = exp(−|(p − c)/r|²)`.
  ```text
  seam = smoothstep(.75, .95, mask.r)                         # уже есть
  protect = 1 − .8*damage_cover                               # d.a из ART-049, уже есть
  occ = clamp(1 − ao_gain*(.18*seam + .34*contact)*protect, .55, 1)
  ALBEDO *= mix(1, occ, .55);  AO = occ;  AO_LIGHT_AFFECT = .15
  ```
- **Ободок — в EMISSION** материала обшивки `HullView` (`shaders/hull_plating.gdshader`), нормаль — **геометрическая**
  (`normalize(ln)` → `VIEW_MATRIX * MODEL_MATRIX`), не нормаль рельефа ART-053 — царапины не блестят:
  ```text
  rim = texture(lut, (U(e), (row(depth) + .5)/8))            # единственная новая выборка
  k = rim.a * rim_gain * alive * (1 − silt_k) * (1 − .55*contact)
  k *= 1 − .55*sin(PI*zap_t/zap_dur)²                         # только пока идёт разряд
  EMISSION += rim.rgb * k
  ```
  `row(depth)` кусочно-линейно: 0→1 на 0…8 м, 1→3 на 8…20, 3→5 на 20…45, 5→6 на 45…90; глубина — `main.helm.depth()`.
  Без TIME и шума.
- **Ил:** `k *= 1 − silt_k`. **«Корпус разрушен» ART-036:** `alive = 1 − smoothstep(0, Wreck.DARK_AT, t)`, 0 до
  `RESTART_AT`, затем `smoothstep(RESTART_AT, Wreck.END, t)`.
- **«Экономно» (ART-044):** `k *= .65`, `contact = 0` (поля не считать), AO только по шву.
- Бюджет: 0 новых вызовов, мешей и Light3D, 1 новая выборка, LUT 8 КиБ; слой `LAYER_WORLD`; изнутри мостика без
  изменений. Палитра холодная, без тёплого и красного (#129).
