# ART-024 — плитка наружной обшивки «Ковчега-7» (принято)

Принятый комплект — три бесшовные карты 1024×1024, одна плитка = **2 × 2 м** (512 px на метр):
- `obshivka-tsvet.png` — цвет: охристый металл #8C806B, сетка 2×4 (панели ≈ 1 × 0,5 м), швы и крепёж #514D43,
  один сервисный лючок, лёгкие пятна; головки на граничных швах собираются из половинок соседних плиток.
- `obshivka-maska.png` — маска, линейные данные (не sRGB): 0 — металл, 128 — пятна/подтёки, 255 — швы и крепёж.
  Вычислена из цвета (R<100 → 255), совпадает со швами пиксель в пиксель.
- `obshivka-obrastanie.png` — отдельный слой ила и биоплёнки (#797C6B, #65766B, #56675F) для нижней половины корпуса.
- `obshivka-list.png` — лист: повтор 3×3 цвета и обрастания, маска, эскиз на боковом виде ART-001.

Issue #126, PR #181 (две правки: пустая рамка у обрастания, затем внутренний период 512 px). Дата: 20.10.2026.
Исходник — ART-001 (`kovcheg-7.md`, `kovcheg-7-rakursy.png`, `kovcheg-7-nad-rifom.jpg`).

## Заметки художника (суть)
- Цвет, маску и обрастание проецировать в одних локальных координатах корабля и с одинаковыми весами смешивания —
  иначе на переходах трипланарной проекции швы цвета и маски разойдутся.
- Обрастание смешивать по **локальной** высоте корпуса (корабль наклоняется): h = 0 у киля, 1 у верха,
  вес `0.65 * (1 - smoothstep(0.15, 0.50, h))`; швы остаются видны поверх; окна, линза, роторы — без обрастания.
- Свечение всех трёх карт — 0; светят окна и прожектор. Красного, надписей и номера нет.
- Лючок повторяется каждые 2 м — свойство одной плитки по заказу.
- Эскиз корпуса на листе — ориентир Imagegen, не снимок Godot: масштаб брать из чисел (2 м), не из числа панелей.

## Решения и привязка к игре
- Приёмка: повтор 3×3 с контрастом ×2,5 без решётки (проверено и заново из PNG); у обрастания нет внутреннего периода
  (корреляция при сдвиге 512 px: −0,08 / −0,01 / −0,05 по X / Y / диагонали), край плитки так же пёстрый, как середина
  (СКО яркости 10,0 у края против 10,5–12,0 в середине); противоположные края совпадают; маска v2 совпадает с цветом
  v2; файлы ≤ 2 МБ (цвет 0,7, маска 0,01, обрастание 1,4, лист 0,9).
- В игре: у мешей корпуса (`hull_mesh.gd`) нет UV — шейдер корпуса берёт карты **трипланарно** в осях корабля (вершины
  в локальных метрах, плитка 2 м), один материал на краску, без новых вызовов отрисовки. Маска: 255 — затемнить и дать
  блеск шву, 128 — пятно. Обрастание — по локальной высоте, вес из заметок художника.
- Перед использованием карты копируются в `textures/hull/` (папка `docs/` не импортируется — `.gdignore`); маску
  импортировать без sRGB. Текстуры 1024² сжать на телефоне (ETC2/ASTC — по умолчанию у импорта Godot).
- Читаемость панелей с 30 м в тумане и в облёте `flyby.gd` художник не проверял — проверить снимком
  `tools/shot.gd flyby=start age=3` при интеграции; если швы тонут, усилить затемнение по маске, а не перерисовывать.
- Интеграция — задача потока А в `ROADMAP.md` («Обшивка ART-024 на корпусе снаружи»).
