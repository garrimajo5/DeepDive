# Огни корпуса снаружи (ART-070)

Заказ #491, принято 09.11.2026 (PR #494, ветка `art/ART-070-ogni-korpusa`, сдача v4, коммит 58bbdb2).

- `ogni-korpusa-plan.png` — схема сверху и сбоку: шесть огней, цвет, форма ореола, режим.
- `ogni-korpusa.json` — таблица огней для встройки (`id`, `pos` в осях корабля, `color`, `mode`) и окна (как в игре).
- `ogni-korpusa-oreol.png` — ореол карточки: RGBA 128², радиальная маска `exp(−5·r²)` с нулевым краем, 8 КБ.
- `ogni-korpusa-sprava.jpg`, `ogni-korpusa-sleva.jpg` — пары «как было / с огнями» (сверху / снизу): корабль на глубине
  45 м (`ship=180,-45,-40`), прожектор выключен, камера ровно в 45 м от точки (0; 1,6; 10) корабля — (±36; 1,6; 37),
  с кормовой стороны, носового окна в кадре нет. Desktop Vulkan (Forward Mobile), 1600×720.

## Решения и привязка к игре
- Приёмка: кадры просмотрены, крупно — тоже. На 45 м огни читаются пятнами ≈ 6–12 px и обводят силуэт без прожектора;
  борта различаются формой и цветом: **левый — вытянутый вертикальный ореол #B8D9E8, правый — круглый #67DDEB**. Красного
  нет (#129). Из рубки (`pilot=1`) кадр до/после совпадает (разница ≤ 11 из 255 — шум), окна не слепят.
- Бюджет (замер художника, одинаковая остановка и 12 кадров стабилизации): +1 вызов (справа 137 → 138, слева 97 → 98),
  без Light3D, одна текстура 8 КБ.

- **Как сделано в пробе** (`capture-v4.gd`, в ветке PR #494): один `MultiMesh` из `QuadMesh` 1×1, материал без света,
  `billboard_mode = ENABLED`, `billboard_keep_scale`, цвет экземпляра — альбедо, прозрачность по альфе карты, depth-test
  включён. Размер × `clamp(дистанция до камеры / 45, 0,3; 1,5)`; центр карточки сдвинут к камере на 1,3 м вдоль луча —
  экранное место то же, корпус ореол не режет. Встройка обновляет масштаб и сдвиг по активной камере каждый кадр
  (облёт, камера с борта, вид изнутри).
- Окна снаружи — материал `main` без изменений (замечание приёмки v1: носовое окно ярче не делать).
- **Предложения художника для встройки** (решает поток А при встройке): огни × `Vitals.lamp_k`; заряд < 15 % —
  проблеск гаснет, ВК 0,35, борта 0,25; заряд 0 — всё гаснет. Пробоина — навигационные огни не меняются. «Корпус
  разрушен» (ART-036) — гаснут за 0,3 с. «Экономно» (ART-044) — без ореолов (или меньше), проблеск — ровный 0,35.
- Не проверено: телефон, движение (мерцание кадр-в-кадр), 12 м и всплытие с ореолами (кадры `para-12`/`para-surface`
  были v1 без ореолов). Это — в задаче встройки.
