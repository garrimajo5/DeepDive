# Повреждения обшивки «Ковчега-7» (ART-049)

Заказ #340, принято 22.10.2026 (PR #390, ветка `art/ART-049-povrezhdeniya`).

- `povrezhdeniya-tsvet.png` — RGBA 1024², бесшовная, плитка 2×2 м как у ART-024: RGB — цвет следов, A — непрозрачность.
- `povrezhdeniya-uroven.png` — L8 1024², порог **потери** корпуса для каждого следа (0 — с первой потери,
  255 — только при нулевой прочности); пиксель в пиксель с цветом, порог продолжен в прозрачное окружение следа.
- `povrezhdeniya-list.png` — корпус сбоку при 100 / 70 / 40 / 15 % и пять видов следа крупно (Blender-примерка
  на геометрии `HullPlan`/`HullMesh`, не игровой кадр).
- `povrezhdeniya-proverka.png` — повтор 3×3 при 15 % (контраст ×1,8) и карта порогов.

На плитку: 100 % — 0 следов, 70 % — 7 (13,5 % площади), 40 % — 12 (24 %), 15 % — 17 (34 %), 0 % — 19 (36 %).
Всего 4 скола краски, 4 группы царапин о камень, 4 вмятины, 5 колец присосок, 2 сварные заплатки.
Палитра: #8C806B оголённый металл, #514D43 / #383730 тени и заплатки, #635C4D края, #BBB49E блики, #181D1B борозды;
красного нет (#129).

## Решения и привязка к игре
- Приёмка: файлы просмотрены; повтор 3×3 без разрывов на стыках, кольца присосок (пустая середина) отличимы от
  вмятин (залитое тёмное углубление), следы в масштабе метровых панелей ART-024, одна семья с ART-023/ART-024.
- В игре: тот же шейдер обшивки `shaders/hull_plating.gdshader`, тот же материал — без новых мешей, Decal-узлов и
  вызовов отрисовки. Только краска METAL с `HullMesh.plated = true` (не окна, линза, роторы, рамки).
- Координаты как у ART-024: `p = local / 2.0`, плоскости `p.zy`, `p.xz`, `p.xy`, веса `pow(abs(n), 4)` с нормировкой.
  Порог сравнивать **на каждой плоскости отдельно** и смешивать уже результаты: `d = clamp(1 - hull/100, 0, 1)`,
  след виден при `d > 0 && d >= uroven`; вес смешивания `A * visible * (1 - 0.55 * smoothstep(0.75, 0.95, mask.r))` —
  швы и крепёж ART-024 остаются читаемыми. Сдвигов не добавлять — уже запечены.
- Импорт: цвет — sRGB, repeat, mipmap; порог — без sRGB, без потерного сжатия, nearest без mipmap (иначе
  пороги смешиваются). Карты копировать в `textures/hull/` (`docs/` не импортируется).
- `hull` — одна uniform на материал (`Vitals.hull`); у гостя — из кадра хоста (`NetSnap`, корпус уже в кадре).
  Жёсткий порог как на листе; плавное появление — короткий переход в шейдере, если на облёте будет «щёлкать».
- Художник не проверял туман, mipmap и свет игрового облёта — при встройке снимки `tools/shot.gd flyby=start` при
  корпусе 100 / 70 / 15 %. Если при 70 % следов не видно с облёта, усилить вес в шейдере, а не перерисовывать.
- Против повтора плитки (#406): в шейдере два слоя карты — как есть и повёрнутый на 90° (× 0,83, сдвиг 0,37/0,61),
  слой выбирает плавный шум по плоскости (`HullMesh.damage_gate`). Нормали следов ART-053 брать в тех же координатах.
- Встройка — задача ROADMAP потока А.
