# ART-028 — экран сбора экипажа перед кооп-забегом

Заказ #222, PR #228 (ветка `art/222-sbor-ekipazha`). Принято 21.10.2026.

Файлы:
- `sbor-ekipazha.png` — главный кадр 2400×1080, экран хоста: три игрока, двое готовы, хост ещё «Ждём», биолог свободен;
  «Готов» доступно, «Начать погружение» отключено;
- `sbor-ekipazha-sostoyaniya.png` — лист 2400×2160, шесть уменьшенных экранов: забеги найдены; в сети никого нет;
  роль уже занята; все готовы у хоста; связь потеряна; гость готов — старт только у хоста.

Фон — собственная генерация по мостику и голостолу ART-002/ART-016 (подложка концепта, не снимок сборки), интерфейс
набран кодом художника. Исходники сборки (`build.py`, фон) при приёмке не перенесены — в игре интерфейс собираем сами.

## Компоновка (для 2400×1080, от левого верхнего угла)

| Элемент | x, y, w, h | Поведение |
|---|---|---|
| Создать забег | 1360, 76, 400, 104 | в поиске; в созданном забеге отключено |
| Подключиться (поиск) | 1790, 76, 400, 104 | к списку забегов; в комнате отключено |
| Строка роли i = 0…3 (П/С/И/Б) | 380, 300 + 130·i, 1640, 112 | строка — не кнопка |
| Выбрать роль | 1540, 308 + 130·i, 468, 96 | только у свободной роли |
| Готов / Отменить готовность | 520, 900, 580, 112 | только свой флаг |
| Начать погружение | 1140, 900, 740, 112 | только у хоста; у гостя — «Ждём начала от хоста» |
| Подключиться к найденному | 1580, 398 / 588, 400, 104 | вход в выбранный забег |
| Обновить список | 900, 900, 600, 112 | повтор поиска |
| Назад к списку | 800, 930, 800, 104 | экран «роль занята» |
| Повторить / К списку забегов | 540 / 1200, 640, 620 / 660, 112 | после потери связи |

Кнопки ≥ 96 px, между ними ≥ 30 px. Углы x < 360 и x > 2040 при y > 760 пусты (крестовина и действие).

## Цвета и шрифт
Фон #0B1C24, строки #102B37 (непрозрачные), акцент #67DDEB, вторичный #9AD9E8, текст #D5E4E8, контур #32616D,
неактивное #6E909A. Роли — кружок с буквой: П #E39E38, С #45C2CC, **И #D5E4E8 (нейтральный, #129)**, Б #73BD5C.
Шрифт — шрифт игры (у художника DejaVu Sans Condensed): заголовок 58, роль и статус 34 полужирный, имя 30,
пояснения 29–32, кнопки 34 полужирный, буква роли 39 полужирный (px при высоте 1080).

## Решения и привязка к игре
- Экран — **2D Control поверх сцены** (`CanvasLayer`, как `VotePanel`/`RouteCard`), не голограмма в перспективе:
  резкость и размеры касаний не зависят от камеры. За ним — камера мостика с затемнением, без новой иллюстрации
  и без новых элементов мира. Крестовина и кнопка действия на этом экране скрыты.
- Размеры — от высоты экрана: px макета × (высота экрана / 1080), по центру; на других пропорциях не растягивать текст.
- Статус не только цветом: готов — галочка + «Готов», ожидание — пустое кольцо + «Ждём», свободно — прочерк вместо
  имени + «Свободно» + кнопка выбора, занято — имя и замок «Занято», своя строка — толще контур и «вы».
- Имя — из настроек телефона или «Игрок N», поля ввода нет; длинное имя — одна строка с многоточием.
- Правила (для сетевого кода этапа «Кооп»): роль закрепляет хост, чужой выбор не перезаписывается; смена своей роли
  снимает готовность; старт — только хост, 2–4 подключённых с разными ролями, все готовы, свободные места старту
  не мешают; при потере связи — «Повторить» / «К списку забегов», готовность сбрасывается; системный «Назад» —
  выход из комнаты к списку. Переходы карточек 0,2 с, без мигания и красного.
- Цвет инженера на экране — нейтральный до решения владельца (#129); после решения поменять только кружок «И».
- Код экрана — задача «Пробный сетевой забег» в ROADMAP (этап «Кооп»); табличка над фигурой — заказ ART-033 (#235),
  одной семьёй с этим экраном. На телефоне с вытянутой руки ещё не проверено — проверить при встраивании.
