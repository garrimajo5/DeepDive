# MOD-005…007 — модели бортовых постов мостика (принято)

Приняты 19.10.2026 (issues #13, #14, #15). Исходник — концепт мостика ART-002 (`mostik.md`, `mostik-plan.png`).
Все файлы — glTF 2.0, одна сетка без трансформов узлов, текстура цвета 1024² внутри GLB, металл #8C806B, красного нет.
Проверены разбором GLB и рендером в Godot (Compatibility). Оси игры: нос −Z, правый борт +X, пол y = 0.

## MOD-005 Пульт энергии — `models/pult-energii.glb`, `models/polzunok.glb`
- Корпус 1,2 × 1,6 × 0,40 м, 1 933 треугольника; лицом в −Z, задняя плоскость z = 0, pivot — центр основания у стены.
  Пять пазов с пиктограммами: двигатели, сонар, жизнь, разряд, прожектор.
- Ручка 0,12 × 0,07 × 0,06 м, 210 треугольников, pivot в центре.
- Светятся полосы в пазах, пиктограммы и вставка ручки (#67DDEB). Эмиссии в материале нет — включать по цветовой маске
  (как огни голостола).
- **Место:** левый борт, `position (−4.9, 0, ≈ −1.2)`, `rotation.y = −90°` (лицом в отсек, +X).
  Ручки — дочерние к корпусу: x −0,34 / −0,17 / 0 / 0,17 / 0,34; код двигает только y (ход до 0,3 м, удобно 0,85…1,15).
  Лицо пульта наклонено: ручка садится в паз при **z = −0,35 + 0,103 · (y − 0,75)** (z −0,43 из заметок художника — ручка висит в воздухе).

## MOD-006 Люк в кормовой переборке — `models/lyuk-rama.glb`, `lyuk-stvorka.glb`, `lyuk-koleso.glb`
- Рама 1,8 × 2,5 × 0,18 м (974 треугольника), чистый проём 1,4 × 2,1 м, pivot — центр низа проёма; низ рамы уходит под пол на 0,18 м.
- Створка 1,6 × 2,3 × 0,08 м (1 114), pivot — центр низа. Колесо Ø 0,5 × 0,151 м (875), pivot — центр ступицы, ось вдоль Z.
- Всё лицом в −Z, ничего не светится.
- **Место:** рама в кормовой переборке мостика, `(0, 0, 2.0)` без поворота. Проём модели 1,4 м, а в оболочке сейчас
  `BridgePlan.HATCH_HALF = 0.6` — расширить вырез до 0,7 (или сжать раму по x × 0,857).
  Створка — дочерняя к раме со смещением `(0, −0.10, +0.14)`, открытие — `position.x` 0 → ±1,75; колесо — дочернее к створке
  в `(0, 1.15, −0.10)`, крутится `rotation.z` перед тем, как створка поедет. Коллизия — простые боксы.

## MOD-007 Сканер биолога — `models/skaner-biologa.glb`
- 0,45 × 1,9 × 1,0 м (x × y × z), 2 011 треугольников; лицом в −X, задняя плоскость x = 0, pivot — центр основания у стены.
- Светятся голубая рамка экрана и кнопка (#67DDEB) — маской. Экран тёмный и пустой: изображение рисует игра.
- **Место:** правый борт, `(4.9, 0, ≈ −1.2)` без поворота. Плоскость экрана игры в осях модели: y 0,40…1,72, z ±0,37,
  x ≈ −0,38 (уточнить на глаз при сборке).
