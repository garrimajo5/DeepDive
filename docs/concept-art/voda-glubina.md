# Цвет воды по глубине (ART-059)

Заказ #425, принято 22.10.2026 (PR #430, ветка `art/ART-059-voda-glubina`).

- `voda-palitra.png` — LUT RGB8 1024×64 (490 байт), sRGB. Глубина идёт **сверху вниз** по 64 строкам: строка `i` —
  `120 * i / 63` м; все столбцы одинаковые. Выборка: `U = 0,5`, `V = (0,5 + 63 * clamp(d / 120, 0, 1)) / 64`, фильтр linear,
  без repeat и mipmap. Промежуточные строки интерполированы в линейном свете.
- `voda-kadry.jpg` — четыре настоящих кадра мостика 1600×720 с примеркой (8, 20, 45, 90 м; 45 и 90 м — на склоне

## Решения и привязка к игре
- Приёмка: кадры и LUT просмотрены; четыре глубины различаются с первого взгляда (голубой → синий → тёмно-синий → почти
  чёрный), на 45–90 м склон читается в прожекторе, тьма вокруг не серая; LUT гладкая, яркость монотонно убывает
  (наибольший шаг строк 7/255), без красного (#129).
- Числа — **конечные** значения `Environment.fog_density`, `ambient_light_energy`, `DirectionalLight3D.light_energy`,
  `tonemap_exposure` (ACES): не умножать повторно на нынешние 0,7 / 1,2 / 0,9 из `OceanView.apply_water`.
- Встройка в `Seabed.Water` (CPU, таблица ключей с линейной интерполяцией цвета в линейном свете — LUT грузить не обязательно)
  вместо двух цветов #1A6676 → #041A22; ниже 120 м — clamp. Переходы плавные, без пресетов скачком.
- Стекло окон не светит само: его цвет умножать на рассеянный свет глубины (иначе бирюзовая плёнка поверх тёмной воды);
  при встройке ART-057 — отражение от света, без эмиссии. Ровную эмиссию льда гасить по глубине (`exp(-depth/16)`),
  потом — маска трещин ART-056.
- Лучи ART-052 и каустики сами слабеют с глубиной и солнцем — не усиливать. Прожектор (энергия 10) не трогать; экспозиция
  и рассеянный свет не растут от прожектора.
- Ил ART-048 главнее: цвет глубины смешивать с `Silt.FAR_COLOR` на `0,75 * k`, плотность `+0,03 * k`, `beam_k` как есть.
- «Экономно» (ART-044): та же таблица и переходы, без новых узлов и проходов.
- Тёмные полутона проверить на телефоне (OLED/IPS) — кадры сняты на настольной Vulkan. Встройка — задача ROADMAP потока А
  (этапы 1–2 `grafika-plan.md`).
