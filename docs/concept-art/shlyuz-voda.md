## Решения и привязка к игре
- Приёмка: файлы просмотрены. С поста в проёме читается тёмная холодная вода с рябью и бликами плафона, а не светлое дно;
  трос даёт кольца, захват с образцом — всплеск; закрытый шлюз — плоскости нет. Блики у ближнего края и устойчивость
  при движении камеры — посмотреть на телефоне.
- **Лунный колодец:** гладь — один `PlaneMesh` 2,2 × 2,2 м (2 треугольника; запас уходит под стенки шахты, иначе по краю
  светит дно), центр в осях корабля (0; `Airlock.Y + 0,03` = −1,12; 22), слой `OceanView.LAYER_SHIP`, без теней, +1 вызов,
  новых Light3D и второго прохода отражения нет. Скрыта при `Airlock.t ≤ 0,02`, открытие — множитель `S(0,02; 0,20; t)`.
- Рябь: две встречные выборки одной карты `uv × 2,75 + clock·(0,018; 0,012)` и `uv × 4,125 − clock·(0,012; 0,015)` (uv —
  по плоскости 2,2 м), XY усредняются; вершины не качаются. Сила `1,20 + 0,80·clamp(|ход|/5) + 0,30·(1 − hull/100)`,
  удар — `+1,10·exp(−t/0,65)` один раз по событию удара (не по уменьшенной прочности каждый кадр).
- Цвет: `Seabed.Water.fog_color(глубина) × 0,65`, центр темнее на 42 %; альфа `clamp(0,80 + 0,13·центр + 0,06·F +
  0,08·Seabed.Water.k(глубина); 0; 0,98)` — сквозь остаток видна уже отрисованная отмель; френель
  `F = 0,02 + 0,98·(1 − N·V)^5`. Блик потолочной полосы трюма (x 0, y 2,98, z 21,75, длина 3,9 м, #C6D6DE) — аналитической
  мягкой маской по отражённому лучу, × `Vitals.lamp_k`; новой лампы не ставить.
- События лебёдки — только с той же плоскости: при пересечении уровня воды нижней точкой захвата/троса вниз — один раз
  «вход» (кольца), вверх — «выход» (всплеск; без образца слабее), по `Samples.hook_local` в состояниях REACH/BACK, не каждое
  обновление; неподвижный трос колец не рождает. Кадры внутри диапазона смешиваются smoothstep, огибающая
  `S(0; 0,06; t)·(1 − S(1; 1,4; t))`.
- «Экономно» (ART-044): та же плоскость, сила ряби × 0,625. Звук не нужен.
- Встроено 23.10.2026: `LockWater`, `LockWaterView`, `shaders/lock_water.gdshader`, карты `textures/shlyuz/` (импорт без
  сжатия, данные без sRGB). Гость в коопе воду шлюза пока не видит (как и крышку — их ставит шаг хоста).
