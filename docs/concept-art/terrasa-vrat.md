## Заметки художника (кратко)
Выращенная складчатая минеральная арка с боковыми пустотами — не дверь, не панель; узнаётся с 100 м по трёхлопастному
силуэту и открытой середине. Человеческое — только охристые кабели, наконечники и хомуты у правой опоры, вне прохода.
| Элемент | Размер |
|---|---|
| Арка с верхушкой | X 120 × Y 58 × Z 23 м; pivot — центр прохода на полу, проход вдоль Z, подход с +Z |
| Свободный проход | X −30…+30 м, Y 0…36 м, насквозь; пустой (без мембран, кабелей, невидимой коллизии) |
| Карман разворота | Ø 100 м, центр (0; 0; +70) локально, воды ≥ 36 м; запас при повороте корабля ≈ 33 м |
| Пол террасы | предложение — глубина 65 м, верх арки на 7 м |
| Гнездо | Ø ≈ 1,6 м, чаша 0,35 м; тройка — треугольник со стороной 4 м |
| Створка | ≈ 1,7 × 1,5 × 0,12 м, скользит по дуге вверх ≈ 1,4 м (без петли и ручки) |
| Диагностика | ≈ 2,8 × 1,8 м, рельеф 0–0,08 м: приподнимаются три сходящиеся жилы |
| Кабели | два, Ø 0,07–0,09 м, ≈ 6 м |

Светятся только редкие колонии полипов в трещинах (#67DDEB, вторичный #9AD9E8); минерал, створки, гнёзда — нет; свечение
не синхронно с ответом. Палитра: #0B1C24, #395361, #82999D, #86BCCB, #67DDEB, #9AD9E8, корабль #8C806B, перемычки #9C633D.
Бюджет модели: LOD0 42 тыс. + LOD1 12 тыс. + LOD2 5 тыс. = 59 тыс. треуг.; 3 материала (минерал до 2048² без emissive,
атлас перемычек до 1024², полипы до 512² с маской свечения); статика объединена, три створки — отдельно со своим pivot.

## Решения и привязка к игре
- **Принято как основа модели** террасы (следующий заказ MOD — по этому листу и схеме габаритов). Размеры модели — из
  таблицы и `terrasa-vrat-gabarity.png`, не из пикселей перспективы.
- **Глубина пола 65 м и стыковка с рельефом** — предложение художника, не решение: проверить при сборке места 07
  (`Seabed`/рельеф первого слоя, координаты места 07 из #818: x = −100, z = −240, корабль на 35 м). Коллизии, инерцию,
  камеру и разворот в кармане проверяет сборка уровня, а не концепт.
- **Диагностика** читается кораблём: заряд — сканер, рельеф — сонар; текст неисправности даёт интерфейс корабля (#818),
  на поверхности пиктограмм и света нет. Створку открывает рабочий-купольник (ART-081) — его вид здесь не задан.
- **Иконки 07/08** — кладём в `textures/places/` под ключами мест, когда места появятся в `Run.PLACES`/карте слоя 1.
  Иконка 08 — условный знак навигации, не новый вид бестиария.
- Свет — только биолюм полипов (маска emissive), отдельных огней на колонии нет.

## Модель MOD-023 (принято 12.11.2026, v21)
Заказ #999, PR #1444 (ветка `art/MOD-023-terrasa-vrat`), четыре круга правок: v10 → v14 → v16 → v21. Файл —
`models/terrasa-vrat.glb` (4,0 МБ); виды — `terrasa-vrat-model.jpg` (спереди, сбоку, три четверти, гнёзда),
`terrasa-vrat-model-nalozhenie.jpg` (LOD0 поверх фронта ансамбля в одном масштабе 8,07 пикс/м, зелёный — проход),
`terrasa-vrat-model-lod.jpg` (три LOD).
- **Габарит** 119,96 × 58,1 × 23,5 м, метры, Y вверх, подход с +Z; pivot (0, 0, 0) — центр прохода на полу.
- **Проход 48 × 22 м** (X −24…+24, Y 0…22, насквозь вдоль Z) — по силуэту ансамбля в одном масштабе (решение 12.11,
  вариант 2): прямоугольник 60 × 36 м из таблицы ART-079 в рисунок не влезает, плечи выступают внутрь на 22–30 м,
  свод проёма ≈ 43 м. Пуст на всех LOD — `test_gate_model.test_passage_empty`.
- **LOD** `LOD0/LOD1/LOD2` — по три сетки (Mineral, HumanCable, Polyps), всего с подвижными 41 192 / 11 675 / 4 798
  треуг.; показывать один LOD за раз. Подвижные — вне LOD: `Stvorka0…2` (pivot (48; 2,5; 11,19), (52; 2,5; 11,19),
  (50; 5,96; 11,19); открытие — поворот по локальной X от 0 до −90°, подъём ≈ 1,42 м) и `Diagnostika` (pivot
  (54,5; 3; 11,585), рельеф 0,07 м) — 1 458 треуг. Гнёзда — у правой опоры, (48…52; 1,8…5,3; 11,8).
- **Материалы**: Mineral (2048², цвет/нормали/ORM, без свечения), HumanCable (#9C633D, без карты), Polyps (маска
  512², свечение #67DDEB/#9AD9E8). Карты в GLB — JPEG; при приёмке `compress/mode=2` (`test_texture_import`).
- **Как есть, без правки:** вблизи пористость и гнёзда грубее листа «контакт» (фактура Meshy), у LOD2 крупные дыры;
  верх кольца снаружи полнее рисунка. Ориентир читается с дальних ракурсов — для места 07 этого достаточно.
- **Встройка — отдельная задача:** заменить временную `GateArch` (`PASS_HALF` 30 → 24, `PASS_TOP` 36 → 22, блоки
  опор по модели), масштаб и пол террасы — по ответу уровней 12.11 (полный рост 120 × 58 м, пол ≈ 66 м, верх на 8 м),
  створки — `EcoLink.PETAL`/`GateDiag.NESTS` на места гнёзд модели, LOD — `visibility_range` по «Обычно»/«Экономно».
- **Встроено (#1757, 13.11):** жёлоб под аркой и карман перед правой опорой (`Seabed.Layer.trough`/`nest_pocket`, пол
  66 м), коллизия по силуэту (`GateArch.SHAPE`), гнёзда диагностики — середины закрытых створок: (48; 1,8), (52; 1,8),
  (50; 5,26) на z 11,8 (`GateDiag.NESTS`, `test_gate_model.test_nests_behind_petals`); створку гнезда 0 поднимает
  купольник (`GateView.set_petal`, поворот по X до −90°).
