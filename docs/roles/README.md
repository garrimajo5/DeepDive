# Роли «Погружения»

Таблица ролей, частоты запуска и матрица полномочий — `docs/PASSPORT.md`. Здесь — по файлу на роль: задание,
документы, границы и **текущий фокус**. Плановый запуск роли (в Claude или Codex) — одна инструкция:

> Ты — роль «<роль>» проекта «Погружение» (GitHub garrimajo5/DeepDive). Склонируй репозиторий, прочитай
> `docs/PASSPORT.md` и `docs/roles/<файл>.md` и работай строго по ним.

Готовые промпты для каждой роли с местом и временем запуска — `PROMPTS.md`.

Файлы ведёт проект-менеджер; роль может попросить поменять частоту или задание (уровень «по умолчанию»).

**В конце сессии** каждая роль, если работала, пишет итог и предложения по улучшению одним комментарием в issue
#1350 «Улучшения» (формат — там). Проект-менеджер разбирает их каждый запуск: мелочь вносит сам, задание или частоту
роли меняет уровнем «по умолчанию», важное (паспорт, деньги, сервисы, новая роль) согласует с владельцем.
