- **Оси Godot совпадают с браузерным прототипом**: y вверх, нос корабля в −Z, правый борт +X. Числа из `js/` переносим
  без смены знака; в Unity-коде pogrujenie x стоит со знаком минус — при переносе оттуда знак x меняем обратно.
  Поворот: `rotation.y` растёт — поворот влево; у игрока и корабля yaw = 0 — лицом к −Z.

  разных точек дало ошибку «на метр» вместо 7 см (#1350, 14.11, #1842).

- Не объявлять `const` вложенных типизированных массивов `Packed*` (`Array[PackedVector3Array]` и т. п.): GDScript 4.7.2
  молча отдаёт нулевые векторы при чтении. Плоский `Array[Vector3]` + срез.

  следующих расходятся на ~1e-4, и детерминированный мир идёт иначе в зависимости от порядка (#1964).
