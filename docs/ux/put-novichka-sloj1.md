## Правила, которых держимся (6", альбомная)

- Крестовина слева внизу и кнопки справа — неприкосновенны: никакая плашка не заходит на их круги, зазор ≥ 16 px при H = 1080.
- Строка приборов — не больше 3 строк; что уже написано на кнопке действия, в строку не дублируем.
- Пилот смотрит в окно: всё, что нужно для курса, — вверху по центру, читается боковым зрением.
- Размеры в макетах — при H = 1080 (как `REF_H` в коде), масштаб `size.y / 1080`.
