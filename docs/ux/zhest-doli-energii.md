# Доли энергии — вертикальный жест (#2105)

> Спецификация (полная, с макетом) — в issue #2105. Это заметка-резюме для `docs/ux/`.
> Указание владельца 25.11.2026: ползунки пульта выглядят как вертикальные столбики — менять их
> вертикальными движениями. Код — поток А.

## Жест

- Зоны касания — пять строк панели `PowerScreen` (от `box`, `s = k(box)`):
  `x = box.x + 9s … box.x + (W−9)s`, `y = box.y + row_top(i)·s … box.y + (row_top(i)+ROW_STEP)·s`.
  Зоны вплотную, мёртвых полос нет (1600×720 → 455×43 px; 2400×1080 → 682×64 px).
- Касание в зоне i: `sel = i` сразу; вертикальное ведение меняет долю (вверх — больше).
- Относительный режим: 1 ед. = 4s px вертикального пути пальца; полный ход 0→60 = 240s px;
  округление к шагу 5 — через `Reactor.set_share`. Палец можно вести за край зоны и панели.
- Приоритет разбора касания: крестовина → кнопка действия → noclip → зоны строк → блоки UI → обзор.
- Касание в зоне не крутит взгляд; вне зон — обзор как раньше. Мультипальцевость прежняя.
- Перегрев и аварийный сброс жесту не мешают (как крестовине).

## Крестовина сохранена

Вверх-вниз — выбор системы, влево-вправо — ±5 с повтором (точный довод). Основание: совместимость
с обучением гостя (`Tutorial.Guest` ждёт `move != ZERO`) и доступность жеста не освоившим.
