# SND-007 — интерфейс и связь: касания, кнопка поста, сообщение связи, тангента

## Решения и привязка к игре
- Принято (поток А, 08.11.2026, по описанию в `notes.md` художника и техпроверке — звук никто из агентов не слышит):
  по рекомендации художника **касание 2** (приглушённый резиновый контакт с низким телом, верха срезаны — мягче при
  частом повторе), **пост 2** (пластиковая защёлка кнопки в стальном корпусе, менее острая, чем тумблер),
  **связь 1** (реле и короткий всплеск помех — яснее «открылась линия»), **тангента 1** на нажатие «Говорить» и
  **тангента 2** (отпускание защёлки с мягким «пш») — на отпускание. Вторые варианты остальных в репозиторий не
  взяты — ссылки «▶ послушать» в PR #1446.
- Техпроверка (python `wave`): все WAV PCM16 стерео 48 кГц, крайние отсчёты нулевые, без постоянной составляющей
  (< 0,3 %). `ui-tap.wav` 0,14 с, пик −8,4 дБ; `ui-post.wav` 0,28 с, −4,4 дБ; `comms-in.wav` 0,80 с, −4,0 дБ;
  `radio-key.wav` 0,32 с, −2,1 дБ; `radio-key-up.wav` 0,36 с, −2,5 дБ (резкий щелчок защёлки — в самом звуке,
  не обрыв). Длины — в рамках заказа. LUFS — по замеру художника: UI ≈ −24, связь ≈ −20.
- Импорт: разовые, без петли, сжатие QOA. Файлы — `audio/ui/`.
- Играют (`UiSound` — файлы и правила, `UiSounds` — `main.ui_sounds`):
  - касание (шина «Интерфейс», −2 дБ) — палец попал в кнопку главного меню, паузы, настроек, журнала
    (`MenuFlow.tap_sound` по `hit`; погашенная кнопка и мимо — тихо); два касания ближе 0,06 с — один щелчок;
  - пост (шина «Интерфейс», 0 дБ) — кнопка действия у поста (`Main.use_post`), и когда пост занят товарищем;
  - связь (шина «Голоса», 0 дБ) — новое сообщение на плашке ART-040 (`Comms.cur`); отложенное (меню, шторка,
    голосование) звучит, когда плашка выйдет; одно на сообщение;
  - тангента (шина «Голоса», −2 дБ) — передача включилась / выключилась (`Radio.wants`): «Нажать и держать» —
    нажали и отпустили, «По голосу» — включили и выключили кнопкой. Рация в игре скрыта до голоса (`Radio.enabled`,
    #634) — услышат, когда её включат.
  Тест — `tests/test_ui_sound.gd`.
- **Проверить на устройстве (тестер):** касание не надоедает (`00a-menu`, `29-nastrojki`, `29c-menu-again`), кнопка
  поста — тумблер, не выстрел (`08-power`, `04-full-ahead`), линия связи — без мелодии и речи (`31-svyaz`).
- Происхождение: все пять — Creator.
