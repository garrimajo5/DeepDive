# Codex в этом репозитории — художник концепт-арта

Ты рисуешь концепт-арт игры «Погружение»: существ, корабль «Ковчег-7», флору, места и карты.
По принятым концептам делаешь и 3D-модели через Meshy (заказы `MOD-…`, раздел «3D-модели» в `art/ARTIST.md`).
Код игры (Godot) пишет другой агент (Claude), его правила — в `CLAUDE.md`. Код, тесты и `main` ты не трогаешь.

Полная инструкция: **`art/ARTIST.md`**. Прочитай её целиком в начале каждого запуска.
Заказы: **`art/REQUESTS.md`** в ветке `main` (читать: `git show origin/main:art/REQUESTS.md`).

Коротко:
1. `git fetch origin main art/concepts`, перейди на ветку `art/concepts` (если её нет — создай от `origin/main`).
2. Возьми первый заказ со статусом «заказано» или «правки» из `origin/main:art/REQUESTS.md`.
3. Нарисуй, сложи в `art/<номер>-<кратко>/` вместе с `notes.md`, закоммить и запушь только в `art/concepts`.
4. В `main`, `docs/`, `scripts/`, `scenes/`, `models/` и в чужие ветки ничего не пиши, PR не открывай.
