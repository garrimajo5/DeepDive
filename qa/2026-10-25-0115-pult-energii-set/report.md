- Коммит: `c3c76a6` (релиз `apk-latest`: «ART-050: экран пульта энергии по макету…» (#565)). Плашка версии «v0.1 · #987 c3c76a6». Прошлый проверенный — `8302c48`.
- В APK нет #566 (ракурс пульта, карточка роли скрыта): слита позже, релиз собран из `c3c76a6`.
- Устройство: эмулятор Pixel 8, Android 17, x86_64 с трансляцией arm64, 2400×1080.
- Сценарий: 419 шагов, дошёл до последнего снимка `29k-sbor-host` (t 115 с). `done=False` в итоге скрипта — сценарий, похоже, не дождался «Готово» после `29k` (предположение: связано с ошибкой 1).

## Ошибки и замечания

### 1. Сеть: на Android не создаётся ни один сокет, «Создать забег» — «Забег не открылся: сеть занята» (новая, баг)
Шаги: меню → «Экипаж» → «Создать забег» (`29k-sbor-host`).
Ожидал: комната хоста — «Ваш адрес», Игрок 1 · вы · хост, «Выбрать роль».
Получил: остался на входе сбора, заголовок «Забег не открылся: сеть занята».

Факт по логу: каждое открытие сокета падает в `socket()` — и маяк поиска, и вход по адресу, и хост:
```
E godot : ERROR: Condition "_sock == -1" is true. Returning: FAILED
E godot :    at: _inet_open (drivers/unix/net_socket_unix.cpp:288)
E godot :        [0] start (res://scripts/core/run_beacon.gd:105)
E godot :        [1] open_lobby (res://scripts/game/main.gd:1374)
...
E godot :        [0] _connect (res://scripts/core/net_link.gd:251)
E godot :        [1] join (res://scripts/core/net_link.gd:238)
...
E godot : ERROR: Condition "!is_open()" is true. Returning: ERR_UNCONFIGURED
E godot :    at: bind (drivers/unix/net_socket_unix.cpp:429)
E godot :        [0] start (res://scripts/core/net_link.gd:81)
E godot :        [1] _lobby_create (res://scripts/game/main.gd:1499)
E godot : ERROR: Couldn't create an ENet host.
```
Факт по репозиторию: `export_presets.cfg:52` — `permissions/internet=false`.
Предположение: без разрешения `INTERNET` Android запрещает `socket()` приложению, поэтому сеть не работает **вообще** (и на телефоне тоже): «Никого нет» в поиске и «Нет ответа» по адресу на этом прогоне — тоже следствие, а не настоящая тишина в сети. Нужно включить `permissions/internet` (и, возможно, `access_network_state`, `change_wifi_multicast_state` для широковещательного маяка) и проверить на двух устройствах. Значит, кооперативные PR #558–#562 на устройстве пока не проверены.

### 2. Шапка сбора экипажа поверх строк приборов (замечание)
`29l-sbor-nikogo`, `29k-sbor-host`: «СБОР ЭКИПАЖА» и «Одна сеть Wi-Fi · …» наложены на затемнённые строки приборов («Мостик · глубина 20 м…», «Бросок крупного хищника…») — текст читается хуже. Ожидал: под экраном сбора строки приборов скрыты, как под паузой.

### 3. Смена уровня графики — долгий кадр (ожидаемо по #563)
`29-grafika-ekonomno`: 2 кадр/с, худший кадр **963 мс** (шаг 326 wait, код 0 мс, отрисовка 2008 мс, видеокарта 4 мс); счётчик на экране — «7 кадр/с». Велика отрисовка — сборка вариантов шейдера при смене теней/MSAA, как предупреждал #563. После этого «Красиво» — 58 кадр/с, худший кадр 62 мс (видеокарта 27 мс). Число «Обычно» против «Экономно» на эмуляторе сравнить нельзя: замер «Экономно» целиком съеден этим кадром.

- `09f-deeper`: 37 кадр/с, худший 53 мс (шаг 151 wait, код 16 мс, отрисовка 12 мс, видеокарта 3 мс) — лучше прошлых ~20 кадр/с.
