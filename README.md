# Погружение (DeepDive)

Кооперативная игра про экипаж батискафа «Ковчег-7» в подлёдном океане планеты Талассия-IV. Godot 4.7.2, Android.

**APK для телефона:** https://github.com/garrimajo5/DeepDive/releases/download/apk-latest/DeepDive.apk
(обновляется после каждого слияния в `main`; при первой установке разрешите установку из браузера).

Управление: крестовина слева — ходьба (за штурвалом — ход и поворот), свайп — обзор, кнопка справа — действие у поста.

- Правила разработки: `CLAUDE.md`, план: `ROADMAP.md`, изменения: `CHANGELOG.md`.
- Мир и бестиарий: `docs/context.txt`, `docs/bestiary.md`; концепт-арт: `docs/concept-art/`.
- Художник (Codex): `AGENTS.md`, `art/ARTIST.md`, заказы — `art/REQUESTS.md`.
- Запуск тестов: `godot --headless --path . --import && godot --headless --path . -s tests/run.gd`.
- Прежние версии (браузерный прототип и Unity) — в замороженном репозитории `garrimajo5/pogrujenie`.
